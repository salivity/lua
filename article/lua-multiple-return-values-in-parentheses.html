Lua Multiple Return Values in Parentheses

In the Lua programming language, enclosing a multiple-return function call within parentheses alters how its results are handled by explicitly truncating the output to a single value. While Lua natively supports returning multiple values from a single function, wrapping that function call in parentheses forces the expression to evaluate to only its first return value, discarding all subsequent returns. This article explains the mechanics behind this truncation behavior, why Lua implements it, and how it is practically used in code.

How Lua Handles Multiple Returns

Functions in Lua can return multiple values simultaneously using commas:

local function getCoordinates()
    return 10, 20, 30
end

Under normal circumstances, Lua adjusts the number of returned values depending on the context in which the function is called:

  • When assigned to a list of variables, Lua maps each returned value to its corresponding variable: local x, y, z = getCoordinates() assigns 10 to x, 20 to y, and 30 to z.
  • When used as the last argument to another function or inside a table constructor, all returned values are passed through: print(getCoordinates()) prints 10 20 30.

The Truncation Rule of Parentheses

In Lua's grammar, enclosing an expression within parentheses (...) forces the expression into a single-value context. When a function returning multiple values is placed inside parentheses, Lua evaluates the function but strictly limits the result of the parenthesized expression to exactly one value—the first one. All additional values are discarded.

Consider the following comparison:

local function getCoordinates()
    return 10, 20, 30
end

-- Standard call: both variables receive values
local a, b = getCoordinates()
print(a, b) -- Output: 10   20

-- Parenthesized call: truncated to the first value
local c, d = (getCoordinates())
print(c, d) -- Output: 10   nil

In the second example, (getCoordinates()) evaluates to just 10. Because only one value exists, c receives 10, and d receives nil.

Practical Applications of Value Truncation

Value truncation is not an accidental side effect; it is an intentional language feature often used to control argument lists and sanitize outputs.

1. Suppressing Secondary Returns in Function Calls

A common use case involves built-in Lua functions like string.gsub, which returns both the modified string and the number of substitutions made:

-- Without parentheses: passes both the string and the count
print(string.gsub("hello world", "l", "x"))
-- Output: hexxo worxd    3

-- With parentheses: suppresses the count, passing only the string
print((string.gsub("hello world", "l", "x")))
-- Output: hexxo worxd

By wrapping string.gsub in parentheses, the integer count is truncated, preventing it from leaking into functions that accept variable arguments (...).

2. Table Constructors

When a multiple-return function is placed at the end of a table constructor, Lua normally appends all return values. Parentheses ensure only one element is inserted:

local list1 = { getCoordinates() }
-- list1 contains { 10, 20, 30 }

local list2 = { (getCoordinates()) }
-- list2 contains { 10 }

Enclosing a function call in parentheses provides an idiomatic, concise mechanism in Lua to enforce single-value evaluation without needing to declare intermediate local variables.
