How to Use table.pack and table.unpack in Lua

In Lua, table.pack and table.unpack are fundamental utility functions used to convert between variable argument lists (varargs) and table structures. While table.pack gathers multiple independent values or arguments into a single indexed table, table.unpack does the reverse by expanding a table's elements into a list of individual values. Together, they allow developers to reliably capture, store, manipulate, and forward argument lists, especially when handling functions with dynamic parameters or values that include nil.

The Purpose of table.pack

Introduced in Lua 5.2, table.pack(...) accepts a variable number of arguments and returns a new sequence containing these elements.

Its primary purpose is to safely store parameter lists, particularly when some arguments might be nil. A standard Lua table treats nil as a non-existent element, which causes the standard length operator (#) to produce unreliable results for tables containing "holes" or trailing nil values.

table.pack solves this issue by automatically adding a field named n to the returned table, which stores the exact count of the arguments passed, regardless of how many nil values are present.

local function captureArgs(...)
    local args = table.pack(...)
    print("Total arguments:", args.n)
    for i = 1, args.n do
        print(i, args[i])
    end
end

captureArgs("apple", nil, "banana", nil)
-- Total arguments: 4

The Purpose of table.unpack

The table.unpack function (formerly the global unpack in Lua 5.1) takes an array-like table and expands its values into a tuple or comma-separated list of returns.

Its main purpose is to supply a dynamically generated list of elements to a function that expects standard arguments. Instead of manually passing each table index, table.unpack extracts all elements across a specified range.

The function signature is table.unpack(list [, i [, j]]):

  • list: The table to unpack.
  • i: The starting index (defaults to 1).
  • j: The ending index (defaults to #list).
local coordinates = {10, 20, 30}

local function setPosition(x, y, z)
    print(string.format("X: %d, Y: %d, Z: %d", x, y, z))
end

-- Passes elements 1, 2, and 3 as distinct arguments
setPosition(table.unpack(coordinates))
-- Output: X: 10, Y: 20, Z: 30

Practical Application: Function Wrapping and Forwarding

The combination of table.pack and table.unpack is essential for creating decorators, middleware, or wrapper functions that log, modify, or delay function calls without losing argument integrity.

local function executeWithLogging(fn, ...)
    -- Pack arguments safely, preserving any nil values
    local args = table.pack(...)
    print("Executing function with " .. args.n .. " argument(s)...")

    -- Unpack using the stored 'n' count to maintain trailing nils
    return fn(table.unpack(args, 1, args.n))
end

local function greet(greeting, target, punctuation)
    print(string.format("%s, %s%s", greeting, target or "stranger", punctuation or "."))
end

executeWithLogging(greet, "Hello", nil, "!")
-- Output:
-- Executing function with 3 argument(s)...
-- Hello, stranger!

By pairing table.pack with table.unpack(table, 1, table.n), developers can maintain exact argument counts and seamlessly pass data across function boundaries in Lua.
