Implementing a Set in Lua with Table Keys

In the Lua programming language, there is no built-in primitive set data structure, but sets can be cleanly and efficiently implemented using standard Lua tables by storing elements as keys mapped to true. This article explains how to represent a set using this pattern, demonstrate constant-time membership testing, insert and remove elements, and implement fundamental set operations like union, intersection, and difference.

The Key-to-True Pattern

Lua tables are associative arrays implemented as hash tables for non-numeric or non-sequential keys. By storing an element as a table key with the value true, you leverage Lua's internal hashing mechanism for instantaneous lookups:

local fruitSet = {
    apple = true,
    banana = true,
    orange = true
}

Because an unassigned table key evaluates to nil, which is falsy in Lua, checking for the existence of an item is both concise and executed in \(O(1)\) time complexity:

if fruitSet["apple"] then
    print("Apple is in the set.")
end

if not fruitSet["grape"] then
    print("Grape is not in the set.")
end

Basic Set Operations

Adding and Removing Elements

To add an element to the set, assign true to the corresponding key. To remove an element, assign nil to that key, which prompts Lua to remove the entry from the internal hash table and allows the garbage collector to reclaim any associated memory:

-- Adding an element
fruitSet["mango"] = true

-- Removing an element
fruitSet["banana"] = nil

Creating Sets from Lists

When converting a standard array-like table (a list) into a set, iterate over the list and assign each value as a key mapped to true:

local function makeSet(list)
    local set = {}
    for _, item in ipairs(list) do
        set[item] = true
    end
    return set
end

local mySet = makeSet({"red", "green", "blue"})

Set Algebra Operations

You can implement standard mathematical operations by iterating over the keys of the sets.

Union

The union contains all elements present in either set:

local function setUnion(setA, setB)
    local result = {}
    for item in pairs(setA) do
        result[item] = true
    end
    for item in pairs(setB) do
        result[item] = true
    end
    return result
end

Intersection

The intersection contains only elements that exist in both sets:

local function setIntersection(setA, setB)
    local result = {}
    for item in pairs(setA) do
        if setB[item] then
            result[item] = true
        end
    end
    return result
end

Difference

The difference (relative complement) contains elements that exist in setA but not in setB:

local function setDifference(setA, setB)
    local result = {}
    for item in pairs(setA) do
        if not setB[item] then
            result[item] = true
        end
    end
    return result
end

Using keys mapped to true provides an idiomatic, lightweight, and performant set implementation in Lua without requiring external libraries or custom metatables for simple use cases.
