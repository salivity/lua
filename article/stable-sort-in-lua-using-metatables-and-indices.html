Stable Sort in Lua Using Metatables and Indices

Lua's built-in table.sort function relies on an unstable sorting algorithm, which means the relative order of elements with equal comparison keys is not guaranteed to be preserved. When dealing with complex lists—such as records, objects, or nested tables—maintaining this original order is often required for secondary sorting or deterministic output. This article details two practical techniques to implement a stable sort in Lua: using temporary indices (the Decorate-Sort-Undecorate pattern) and leveraging metatables with auxiliary lookup tables for seamless tie-breaking.

The Instability of table.sort

Standard Lua implements an introsort or quicksort variant in C. When two elements evaluate as neither less than nor greater than each other according to a custom comparator function, their positions can shift arbitrarily relative to each other during partitioning.

To make the sort stable, you must provide a deterministic tie-breaker when two primary values are equal. The most reliable tie-breaker is each element's original position (index) in the source array.

Method 1: Temporary Indices (Decorate-Sort-Undecorate)

The simplest and most portable approach is the Decorate-Sort-Undecorate (DSU) pattern. You package each element along with its original index into a temporary container, perform the sort using the original index as a tie-breaker, and then unpack the values back into the table.

local function stable_sort(list, comp)
    -- Default comparator if none provided
    comp = comp or function(a, b) return a < b end

    local decorated = {}
    for i = 1, #list do
        decorated[i] = { value = list[i], index = i }
    end

    table.sort(decorated, function(a, b)
        if comp(a.value, b.value) then
            return true
        elseif comp(b.value, a.value) then
            return false
        else
            -- Keys are equivalent; preserve original order
            return a.index < b.index
        end
    end)

    for i = 1, #list do
        list[i] = decorated[i].value
    end

    return list
end

Example Usage

local users = {
    { name = "Alice", score = 10 },
    { name = "Bob",   score = 20 },
    { name = "Carol", score = 10 },
    { name = "Dave",  score = 20 },
}

stable_sort(users, function(a, b)
    return a.score < b.score
end)

for _, user in ipairs(users) do
    print(user.name, user.score)
end
-- Output:
-- Alice   10
-- Carol   10
-- Bob     20
-- Dave    20

Method 2: Metatables and Index Tracking

If you are sorting complex tables or objects, you can use metatables to encapsulate tie-breaking logic without manually unpacking containers. By mapping each table reference to its original index in an external lookup table, you can define an __lt metamethod that resolves ties automatically.

local function stable_sort_meta(list, comp)
    comp = comp or function(a, b) return a < b end

    -- Map original indices to table references
    local indices = {}
    for i = 1, #list do
        indices[list[i]] = i
    end

    -- Create a shared metatable with the tie-breaking __lt metamethod
    local mt = {
        __lt = function(a, b)
            if comp(a, b) then
                return true
            elseif comp(b, a) then
                return false
            else
                return indices[a] < indices[b]
            end
        end
    }

    -- Apply metatable to each element
    for i = 1, #list do
        setmetatable(list[i], mt)
    end

    -- Call standard table.sort without an inline comparator
    table.sort(list)

    -- Clean up metatables
    for i = 1, #list do
        setmetatable(list[i], nil)
    end

    return list
end

Note: This method requires that list items are distinct reference types (tables) and do not rely on an existing custom __lt metamethod that cannot be temporarily overridden.

Choosing Between the Approaches

  • Temporary Indices (DSU) works with all data types (primitives, tables, strings) and does not interfere with existing metatables. It creates temporary wrapper tables, which incurs a small garbage collection overhead, but is universally safe.
  • Metatable Mapping avoids allocating wrapper tables for each index, but relies on mutating metatables during the sort and requires elements to be unique table references.

For general purposes, the temporary index pattern is typically the most robust choice in Lua for implementing stable sorting.
