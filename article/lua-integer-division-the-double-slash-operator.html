Lua Integer Division: The Double Slash Operator

In modern versions of Lua (version 5.3 and later), the double slash (//) operator performs floor division, computing the quotient of two numbers and rounding it down toward negative infinity. This operator was introduced alongside Lua's distinct integer subtype to provide explicit integer arithmetic. This guide outlines how the // operator behaves, how it determines result types, how it handles negative numbers, and how it manages edge cases like division by zero.

Floor Rounding Behavior

Unlike division operators in languages like C or Java that truncate toward zero, Lua's // operator strictly floors the result toward negative infinity.

  • Positive results: The fractional part is discarded. For example, 7 // 2 yields 3.
  • Negative results: The result rounds down to the next lower integer. For example, -7 // 2 yields -4, rather than -3.

This behavior ensures consistency with the mathematical definition of floor division and the modulo operator (%), adhering to the identity: a == (a // b) * b + (a % b).

Operand Types and Output Types

Lua numbers can be represented internally as either 64-bit integers or 64-bit floats. The // operator adapts its output type based on the input operands:

  • Integer and Integer: If both operands are integers, the result is an integer. For instance, 9 // 4 produces the integer 2.
  • Mixed Types or Floats: If either operand is a floating-point number, the operation still rounds down, but the return value is a float with an integral value. For example, 9.0 // 4 or 9 // 4.0 yields the float 2.0.

Difference Between / and //

In Lua 5.3 and newer, the single slash (/) is dedicated float division. It always converts operands to floats and returns a float, meaning 4 / 2 evaluates to 2.0.

Conversely, // computes the floor. When given two integers that divide evenly, 4 // 2 retains the integer subtype and returns 2.

Division by Zero

The behavior of // during a division by zero depends directly on operand types:

  • Integer division by zero: Dividing an integer by the integer 0 (e.g., 5 // 0) raises a runtime error: attempt to divide by zero.
  • Float division by zero: If either operand is a float (e.g., 5.0 // 0 or 5 // 0.0), Lua follows IEEE 754 floating-point standards. The expression evaluates without an error to inf, -inf, or nan (in the case of 0.0 // 0.0), typed as a float.
