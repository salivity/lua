Lua __call Metamethod: Calling Tables as Functions

In the Lua programming language, tables are the primary data structure, but they can also emulate functions through metatables. By attaching a metatable with a defined __call metamethod to a table, Lua allows that table to be invoked using standard function call syntax table(). This article explains the underlying mechanics of the __call metamethod, provides clear code implementations, and highlights practical applications such as object-oriented constructors and stateful closures.

Understanding the __call Metamethod

Normally, attempting to execute a table like a function in Lua results in a runtime error: attempt to call a table value. When Lua encounters an invocation on a non-function value, it checks whether the value has an associated metatable and looks for the __call field within it.

If __call is defined and contains a function, Lua executes that function instead of throwing an error. The first argument passed to the __call function is always the table itself, followed by any additional arguments supplied during the invocation.

Basic Syntax and Implementation

To make a table callable, assign it a metatable containing the __call key mapped to a function:

-- Define the target table
local Greeter = {
    greeting = "Hello"
}

-- Define the metatable
local mt = {
    __call = function(self, name)
        return self.greeting .. ", " .. name .. "!"
    end
}

-- Attach the metatable to the table
setmetatable(Greeter, mt)

-- Invoke the table directly
print(Greeter("Alice")) -- Output: Hello, Alice!
print(Greeter("Bob"))   -- Output: Hello, Bob!

In this example, calling Greeter("Alice") is syntactically equivalent to calling the metamethod function with mt.__call(Greeter, "Alice").

Practical Applications

1. Object Constructors (Class Instantiation)

A widespread pattern in Lua object-oriented programming is using __call to avoid writing explicit constructor method names like .new().

local Vector = {}
Vector.__index = Vector

function Vector.new(x, y)
    local instance = setmetatable({ x = x, y = y }, Vector)
    return instance
end

-- Allow Vector(x, y) instead of Vector.new(x, y)
setmetatable(Vector, {
    __call = function(self, x, y)
        return self.new(x, y)
    end
})

local v = Vector(10, 20)
print(v.x, v.y) -- Output: 10  20

2. Functors and Stateful Execution

Unlike standard functions, which rely on external closures or global variables to retain mutable state, a callable table can encapsulate state directly inside its own key-value pairs:

local Counter = { count = 0 }

setmetatable(Counter, {
    __call = function(self, step)
        step = step or 1
        self.count = self.count + step
        return self.count
    end
})

print(Counter())   -- Output: 1
print(Counter(5))  -- Output: 6
print(Counter.count) -- Output: 6

3. Transparent Memoization and Caching

The __call metamethod can act as an access layer that checks for cached results before executing an expensive calculation:

local Factorial = {
    cache = { [0] = 1, [1] = 1 }
}

setmetatable(Factorial, {
    __call = function(self, n)
        if not self.cache[n] then
            self.cache[n] = n * self(n - 1)
        end
        return self.cache[n]
    end
})

print(Factorial(5)) -- Output: 120

Summary

The __call metamethod bridges the gap between data structures and functional programming in Lua. By intercepting calls to table values, it enables concise APIs, object factory patterns, and self-contained stateful operations without sacrificing Lua's characteristic simplicity.
