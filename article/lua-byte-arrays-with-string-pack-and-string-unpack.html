Lua Byte Arrays with string.pack and string.unpack

This article provides an overview of how the Lua programming language handles binary data using its native string library. Lua represents raw byte sequences using standard, 8-bit clean strings, eliminating the need for a dedicated byte array data type. By utilizing the string.pack and string.unpack functions introduced in Lua 5.3, developers can efficiently serialize Lua values into binary layouts and deserialize structured binary buffers back into native variables.

Binary Data Representation in Lua

In Lua, strings are arbitrary sequences of bytes. Unlike languages where strings are strictly null-terminated or restricted to specific text encodings (like UTF-8 or ASCII), Lua strings are 8-bit clean and length-aware. A Lua string can hold any byte value from 0x00 to 0xFF.

Because of this design, a raw byte array is simply represented as a standard Lua string. However, because Lua strings are immutable, modifying a byte sequence requires creating a new string or operating on intermediate structures such as tables of integer byte values.

Serializing Data with string.pack

The string.pack function serializes primitive values—such as numbers, booleans, and other strings—into a binary string according to a specified format string.

Syntax

local packed_bytes = string.pack(fmt, v1, v2, ...)
  • fmt: A string defining the layout and types of the values.
  • v1, v2, ...: The values to pack into the binary sequence.

Format Specifiers

The format string uses specific characters to control alignment, endianness, and data types:

  • Endianness:
    • <: Little-endian.
    • >: Big-endian.
    • =: Native endianness (default).
  • Integer Types:
    • b / B: Signed / unsigned 1-byte integer (char).
    • h / H: Signed / unsigned 2-byte integer (short).
    • l / L: Signed / unsigned native long.
    • j / J: Signed / unsigned Lua integer (lua_Integer).
    • i[n] / I[n]: Signed / unsigned integer of n bytes (e.g., I4 for a 32-bit unsigned integer).
  • Floating-Point Types:
    • f: Single-precision float (4 bytes).
    • d: Double-precision float (8 bytes).
    • n: Lua number (lua_Number).
  • Strings and Bytes:
    • c[n]: Fixed-length string of n bytes.
    • z: Zero-terminated string.
    • s[n]: String preceded by an unsigned integer length of n bytes.
  • Padding and Alignment:
    • x: One byte of padding (zero-filled).
    • X[n]: Aligns according to an n-byte boundary.

Example: Packing a Binary Header

-- Pack a 16-bit identifier, an 8-bit flags field, and a 32-bit float in big-endian format
local id = 0x1020
local flags = 0x05
local value = 42.5

local binary_packet = string.pack(">I2 B f", id, flags, value)
print(#binary_packet) -- Outputs: 7 (2 + 1 + 4 bytes)

Deserializing Data with string.unpack

The string.unpack function reverses the packing process by reading values out of a binary string according to a format string.

Syntax

local v1, v2, ..., next_pos = string.unpack(fmt, s [, init])
  • fmt: The format string matching the layout of the data.
  • s: The binary string to read from.
  • init: An optional 1-based index indicating where to begin reading (defaults to 1).

In addition to returning the unpacked values, string.unpack returns a final value representing the 1-based index in the string where the next unread byte begins. This is useful for processing streams or sequential packets.

Example: Unpacking Binary Data

local binary_packet = string.pack(">I2 B f", 0x1020, 0x05, 42.5)

-- Unpack the binary packet
local id, flags, value, next_offset = string.unpack(">I2 B f", binary_packet)

print(string.format("ID: 0x%X", id))      -- ID: 0x1020
print(string.format("Flags: %d", flags))  -- Flags: 5
print(string.format("Value: %.1f", value))-- Value: 42.5
print("Next byte position:", next_offset) -- Next byte position: 8

Manipulating Byte Arrays

Because Lua strings cannot be modified in place, updating a single byte or value within a packed binary structure requires extracting, altering, and repacking the components, or slicing the string with string.sub.

Modifying Specific Bytes via Unpack and Repack

local packet = string.pack("<I4 I4", 100, 200)

-- Unpack the two values
local val1, val2 = string.unpack("<I4 I4", packet)

-- Modify the second value and repack
val2 = val2 + 50
local modified_packet = string.pack("<I4 I4", val1, val2)

Direct Byte-Level Updates via Tables

When performing frequent, arbitrary byte modifications, it is more efficient to convert the binary string into a table of integers, manipulate the elements directly, and reconstruct the binary string:

local data = string.pack("c4", "test")

-- Convert byte string into a mutable table of byte values
local bytes = { string.byte(data, 1, #data) }

-- Modify the first byte (change 't' to 'b')
bytes[1] = string.byte("b")

-- Reconstruct the raw binary string
local updated_data = string.char(table.unpack(bytes))
print(updated_data) -- Outputs: best
