How to Use table.move in Lua 5.3

Introduced in Lua 5.3, the table.move function provides an efficient, built-in mechanism for copying contiguous ranges of elements from one table to another or within the same table. This article covers the syntax of table.move, how its parameters dictate the range and destination of data, its internal handling of overlapping ranges, and practical code examples demonstrating its functionality.

Syntax and Parameters

The function signature for table.move is:

table.move(a1, f, e, t [, a2])
  • a1: The source table containing the elements to copy.
  • f: The starting index (inclusive) of the range in a1.
  • e: The ending index (inclusive) of the range in a1.
  • t: The target index where the copied range will begin.
  • a2 (optional): The destination table. If omitted, it defaults to a1, copying elements within the source table itself.

The function returns the destination table (a2 if provided, otherwise a1).

How It Works

The function copies elements from a1[f] through a1[e] into the destination table starting at position t. The assignment behaves as follows:

a2[t], a2[t+1], ..., a2[t + (e - f)] = a1[f], a1[f+1], ..., a1[e]

If e < f, the function performs no operations and simply returns the destination table. Because the function is implemented in C, it runs significantly faster than an equivalent manual for loop in pure Lua.

Handling Overlapping Ranges

When moving elements within the same table (i.e., when a2 is omitted or a1 == a2), ranges may overlap. Similar to the standard C library function memmove, table.move safely handles overlapping memory spaces.

If the destination index t is greater than f, the function copies elements in reverse order (from back to front) to avoid overwriting elements before they are read. If t is less than f, it copies from front to back.

Examples

1. Copying Between Two Tables

local source = {"a", "b", "c", "d"}
local dest = {}

-- Copy indices 2 through 4 from source to dest starting at index 1
table.move(source, 2, 4, 1, dest)

-- dest now contains: {"b", "c", "d"}

2. Shifting Elements Within the Same Table

You can use table.move to insert an element at a specific index without using table.insert, which is useful for large arrays:

local list = {10, 20, 40, 50}

-- Shift elements at indices 3 and 4 forward by 1
table.move(list, 3, #list, 4)

-- Insert the missing value into the gap
list[3] = 30

-- list now contains: {10, 20, 30, 40, 50}

3. Appending One Table to Another

local t1 = {"first", "second"}
local t2 = {"third", "fourth"}

-- Append all elements of t2 to the end of t1
table.move(t2, 1, #t2, #t1 + 1, t1)

-- t1 now contains: {"first", "second", "third", "fourth"}
