How lua_sethook Installs Debugging Hooks in Lua

The lua_sethook function is a core utility in the Lua C API that allows developers to monitor and intercept the execution of Lua scripts for debugging and profiling purposes. By registering a custom callback function along with an event mask and an instruction counter, lua_sethook configures the Lua virtual machine to automatically trigger notifications during function calls, function returns, line executions, and after a set number of VM instructions.

The lua_sethook Signature

The function is defined in the Lua C API as follows:

void lua_sethook (lua_State *L, lua_Hook f, int mask, int count);
  • L: The Lua execution state being monitored.
  • f: The callback function of type lua_Hook, which has the signature void (*lua_Hook) (lua_State *L, lua_Debug *ar). Passing NULL disables all hooks.
  • mask: A bitwise OR combination of flags (LUA_MASKCALL, LUA_MASKRET, LUA_MASKLINE, and LUA_MASKCOUNT) designating which events should fire the hook. Setting this to 0 disables hook execution.
  • count: An integer indicating how many VM instructions must run between invocations when LUA_MASKCOUNT is active.

Installing Call and Return Hooks

Call hooks are installed by including the LUA_MASKCALL flag in the mask argument, while return hooks use LUA_MASKRET.

When the Lua virtual machine executes a function call (via opcodes such as OP_CALL or internal C dispatchers), it inspects the state's active hook mask. If LUA_MASKCALL is present, the VM interrupts normal execution and invokes the callback function f, setting the event field in the lua_Debug structure to LUA_HOOKCALL (or LUA_HOOKTAILCALL for tail calls). Similarly, whenever a function returns via an opcode like OP_RETURN, the presence of LUA_MASKRET causes the VM to invoke f with an event type of LUA_HOOKRET.

Installing Line Hooks

A line hook is activated by setting the LUA_MASKLINE bit in the mask parameter.

Lua bytecode associates instruction offsets with the source line numbers from which they were compiled. When LUA_MASKLINE is enabled, the interpreter evaluates the line number of the current instruction against the line number of the previously executed instruction. If the line changes, or if the interpreter executes a jump or branch to a different section of code, it halts execution to invoke the registered hook with ar->event set to LUA_HOOKLINE. This mechanism enables step-by-step debugging.

Installing Count Hooks

A count hook is configured by setting the LUA_MASKCOUNT flag in the mask and supplying a positive integer value for count.

Internally, the Lua virtual machine maintains an instruction counter in the lua_State. Every time the interpreter processes an instruction cycle, it decrements this counter. When the counter reaches zero, Lua triggers the callback function f with ar->event set to LUA_HOOKCOUNT, resets the counter back to the specified count threshold, and resumes script execution. This hook is primarily used to implement execution timeouts, preemptive multitasking, or sampling-based profilers.

Hook Callback Handling

When any of these hooks fire, the callback function receives a pointer to an unpopulated lua_Debug structure containing only the event code and, for line hooks, the currentline field. To retrieve deeper context—such as the source file, function name, or local variables—the callback must pass this lua_Debug pointer to lua_getinfo with the appropriate query flags. Hooks can be completely removed at any time by calling lua_sethook(L, NULL, 0, 0).
