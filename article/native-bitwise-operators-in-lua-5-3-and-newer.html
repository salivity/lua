Native Bitwise Operators in Lua 5.3 and Newer

Starting with Lua 5.3, the language natively supports integer subtypes and a dedicated suite of bitwise operators. Prior versions required third-party C modules or the standard bit32 library introduced in Lua 5.2. This guide provides a concise overview of the six native bitwise operators in modern Lua, explains their syntax and behavior, and demonstrates how to apply them to integer data types.

The Six Bitwise Operators

Lua 5.3 represents standard integers as 64-bit signed values. The native bitwise operators operate directly on these integer values:

  • Bitwise AND (&): Compares each bit of two numbers; yields 1 if both bits are 1, otherwise 0.
  • Bitwise OR (|): Compares each bit; yields 1 if at least one corresponding bit is 1.
  • Bitwise XOR (~ binary): Compares each bit; yields 1 if the bits are different, and 0 if they are identical.
  • Bitwise NOT (~ unary): Inverts all bits (flips 0 to 1 and 1 to 0). Note that Lua uses the tilde ~ for both binary XOR and unary NOT.
  • Logical Right Shift (>>): Shifts the bits of the first operand to the right by the number of positions specified by the second operand. Vacant bits are filled with zeros.
  • Logical Left Shift (<<): Shifts the bits to the left, discarding bits that exceed the integer width and filling vacant positions with zeros.

Basic Syntax and Examples

You can use these operators inline just like standard arithmetic operators:

local a = 0x0F  -- 00001111 in binary (15 in decimal)
local b = 0x33  -- 00110011 in binary (51 in decimal)

-- Bitwise AND
local and_result = a & b
print(string.format("0x%X", and_result)) -- Output: 0x3

-- Bitwise OR
local or_result = a | b
print(string.format("0x%X", or_result))  -- Output: 0x3F

-- Bitwise XOR
local xor_result = a ~ b
print(string.format("0x%X", xor_result)) -- Output: 0x3C

-- Bitwise NOT
local not_result = ~a
print(string.format("0x%X", not_result)) -- Output: 0xFFFFFFFFFFFFFFF0

-- Left Shift
local lshift_result = a << 2
print(string.format("0x%X", lshift_result)) -- Output: 0x3C

-- Right Shift
local rshift_result = b >> 2
print(string.format("0x%X", rshift_result)) -- Output: 0xC

Type Constraints and Conversion Rules

Bitwise operators require operands to be integers or values that can be converted to integers:

  1. Floats: If a float value has an exact integer equivalent (such as 5.0), Lua automatically converts it into an integer. If a float has a fractional part (such as 5.5), Lua throws a runtime error.
  2. Strings: Strings representing integers are automatically coerced into integers.
  3. Shift Limits: When shifting by a negative value or by a value greater than or equal to the total bit width (typically 64 bits), the result is 0. Left shifts do not perform sign extension; shifted-in bits are always zero.
