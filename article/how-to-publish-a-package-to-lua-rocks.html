How to Publish a Package to LuaRocks

Publishing custom Lua libraries to the public LuaRocks repository allows developers to share reusable modules with the global Lua community. This guide covers the complete step-by-step workflow for distributing your code, from structuring your project and creating a rockspec manifest file to authenticating your account and uploading the package using the LuaRocks command-line interface.

1. Create a LuaRocks Account

To publish packages to the public repository, you must have an active LuaRocks account:

  1. Visit luarocks.org and register for an account.
  2. Log in and navigate to your Settings page.
  3. Locate the API Keys section and generate an API key.
  4. Copy the key; you will need it to authenticate uploads from your terminal.

2. Prepare Your Library Repository

Host your library code in a publicly accessible Git repository, such as on GitHub or GitLab.

Organize your project directory:

my-library/
├── src/
│   └── mylibrary.lua
├── LICENSE
└── README.md

Once your code is ready, commit your changes, push them to your remote repository, and create a Git release tag (for example, v1.0.0). LuaRocks relies on static release archives or specific tags to download and build your package.

3. Generate the Rockspec File

A .rockspec file is a Lua script containing package metadata, source URLs, dependencies, and build instructions. You can generate a template using the luarocks write_rockspec command:

luarocks write_rockspec https://github.com/username/my-library/archive/refs/tags/v1.0.0.tar.gz

Alternatively, you can manually create a file named my-library-1.0.0-1.rockspec:

package = "my-library"
version = "1.0.0-1"

source = {
   url = "git+https://github.com/username/my-library.git",
   tag = "v1.0.0"
}

description = {
   summary = "A brief description of your library",
   detailed = "A longer explanation of what your module does.",
   homepage = "https://github.com/username/my-library",
   license = "MIT"
}

dependencies = {
   "lua >= 5.1"
}

build = {
   type = "builtin",
   modules = {
      ["my-library"] = "src/mylibrary.lua"
   }
}

4. Test the Rockspec Locally

Before publishing, verify that the rockspec builds and installs properly on your machine:

luarocks make my-library-1.0.0-1.rockspec

Test loading the library in the Lua interpreter:

lua -l my-library

If it loads without errors, the package is configured properly.

5. Upload to LuaRocks

Authenticate your local LuaRocks CLI with the API key generated in Step 1:

luarocks config api_key YOUR_API_KEY

Once authenticated, upload your rockspec:

luarocks upload my-library-1.0.0-1.rockspec

The CLI tool will automatically validate the file, upload the rockspec, and trigger the build on the LuaRocks servers.

6. Verify Installation

After the upload completes, your package will appear on your LuaRocks user profile. Verify that users can install it globally by running:

luarocks install my-library
