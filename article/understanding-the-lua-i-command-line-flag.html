Understanding the Lua -i Command Line Flag

The -i command-line flag in the standalone Lua executable instructs the interpreter to enter interactive mode immediately after executing a specified script. This article explains how the -i option alters standard execution behavior, preserves script state for runtime inspection, and serves as an effective tool for debugging and exploratory testing.

When executing a script using the standard command lua script.lua, Lua compiles the file, runs its code to completion, and terminates the process, returning control back to the operating system shell. Any variables, functions, and state created during execution are discarded upon exit.

Using the -i flag changes this behavior:

lua -i script.lua

With this command, Lua executes script.lua in its entirety. Instead of exiting when the script finishes, the interpreter presents an interactive prompt (the standard Lua REPL, typically indicated by >).

State Preservation and Inspection

The primary benefit of entering interactive mode via -i is that the entire global environment of the executed script remains in memory. Developers can:

  • Inspect Variables: Query global variables, tables, or configuration values defined in the script to verify their end-of-run state.
  • Invoke Functions: Manually call functions declared inside the script with arbitrary arguments to test edge cases without modifying the source file.
  • Modify State: Alter values in memory and rerun specific logic interactively to see how changes affect output.

For example, consider a file named math_utils.lua:

function add(a, b)
    return a + b
end

total = add(10, 20)

Running lua -i math_utils.lua loads the file and displays the prompt:

> print(total)
30
> print(add(5, 15))
20

Passing Arguments

The -i flag works seamlessly alongside script arguments. Any arguments passed after the script filename remain accessible inside the script through the arg table:

lua -i process.lua input.txt output.txt

In this scenario, process.lua processes the arguments, executes its routines, and then drops into the interactive shell.

Combining with the -e Flag

The -i flag can also be paired with the -e flag, which executes code provided directly as a string from the command line:

lua -i -e "x = 42"

This runs the inline chunk first and immediately opens the interactive console with x accessible.

To exit interactive mode when finished, you can send an end-of-file (EOF) signal (Ctrl+D on Unix-like systems, Ctrl+Z followed by Enter on Windows) or call os.exit().
