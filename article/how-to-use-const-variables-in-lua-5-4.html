How to Use Const Variables in Lua 5.4

Lua 5.4 introduced variable attributes, bringing native compile-time constants to the language through the <const> annotation. This article provides a clear overview of what <const> variables are, how to declare them using the correct syntax, and the operational rules regarding immutability and tables in Lua.

What are Const Variables in Lua 5.4?

In Lua 5.4, a const variable is a local variable that cannot be reassigned after its initial definition. Prior to this version, Lua lacked native constant support, forcing developers to rely on naming conventions (such as all-caps variable names) or complex metatable tricks using __newindex to prevent modifications.

Const variables are enforced at compile time. If code attempts to assign a new value to a declared constant, Lua halts execution and raises a syntax error before running the script.

How to Declare Const Variables

You declare a const variable using the local keyword followed by the variable name, the <const> attribute, and an immediate assignment.

local MAX_USERS <const> = 100
local API_URL <const> = "https://api.example.com"

There are two strict syntax rules when declaring const variables:

  1. Scope: They must be local. You cannot declare global const variables.
  2. Initialization: They must be assigned a value at the moment of declaration. Leaving them uninitialized (e.g., local x <const>) triggers an error.

You can also apply the <const> attribute to multiple variables in a single statement:

local WIDTH <const>, HEIGHT <const> = 1920, 1080

Reassignment Behavior

Attempting to rebind a const variable generates a compile-time error:

local TIMEOUT <const> = 30
TIMEOUT = 60 -- Error: attempt to assign to const variable 'TIMEOUT'

Table Mutability (Shallow Const)

The <const> attribute enforces reference immutability, not structural immutability. When you assign a table to a <const> variable, the variable cannot be pointed to a different table or primitive value, but the internal contents of the table can still be modified:

local CONFIG <const> = { port = 8080 }

-- This is allowed:
CONFIG.port = 9000

-- This is NOT allowed:
CONFIG = { port = 9000 } -- Error: attempt to assign to const variable 'CONFIG'

To create completely immutable tables, you must combine <const> with a custom metatable that blocks the __newindex metamethod.

Advantages of Using <const>

  • Error Prevention: Prevents accidental reassignment of configuration values, identifiers, and dependencies.
  • Compiler Optimization: In Lua's register-based virtual machine, const variables allow the compiler to optimize bytecode generation because the variable's value and register mapping remain static.
  • Code Readability: Explicitly signals developer intent within local scopes and functions.
