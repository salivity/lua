Prototype OOP with Lua Tables and Metatables

Lua does not feature a built-in class-based object-oriented programming (OOP) model; instead, it relies on prototype-based inheritance implemented through its fundamental data structure: the table. By leveraging metatables and the __index metamethod, developers can link objects together so that one table falls back to another for missing properties and methods. This article explains how tables, metatables, and the __index fallback mechanism combine to create reusable prototypes, instantiate new objects, and establish inheritance hierarchies in Lua.

Tables as Objects

In Lua, objects are simply tables that hold both state (data) and behavior (functions). Functions stored within tables can act as methods, and Lua provides the colon syntax (:) as syntactic sugar to automatically pass the calling table as an implicit first parameter named self.

local Account = { balance = 0 }

function Account:deposit(amount)
    self.balance = self.balance + amount
end

The definition Account:deposit(amount) is equivalent to Account.deposit(self, amount), allowing methods to operate directly on the instance's internal data.

The Role of Metatables and __index

Metatables allow you to change the behavior of tables in predefined ways. For prototype-based OOP, the critical metamethod is __index.

When Lua accesses a key in a table that does not exist, it checks if that table has a metatable with an __index field:

  • If __index is a table, Lua looks up the key in that table.
  • If __index is a function, Lua executes it with the original table and the requested key as arguments.

By assigning a prototype table as the __index target of an instance's metatable, the instance automatically inherits all fields and functions defined in the prototype.

Creating a Prototype Constructor

To implement instantiable prototypes, a constructor pattern is standard. Typically, the prototype table sets its own __index field to itself, then assigns itself as the metatable for every new table created.

local Vector = {}
Vector.__index = Vector

function Vector:new(x, y)
    local instance = setmetatable({}, self)
    instance.x = x or 0
    instance.y = y or 0
    return instance
end

function Vector:magnitude()
    return math.sqrt(self.x^2 + self.y^2)
end

-- Instantiation
local v = Vector:new(3, 4)
print(v:magnitude()) -- Output: 5

When v:magnitude() is called, Lua fails to find magnitude directly on v. It inspects v's metatable (which is Vector), checks Vector.__index, finds Vector.magnitude, and executes it with v as self.

Implementing Inheritance Chains

Prototypal inheritance allows one prototype to derive from another. To inherit methods from a base prototype, a derived prototype simply sets its own metatable to the base prototype.

-- Base Prototype
local Animal = {}
Animal.__index = Animal

function Animal:new(name)
    local instance = setmetatable({}, self)
    instance.name = name
    return instance
end

function Animal:speak()
    return self.name .. " makes a sound."
end

-- Derived Prototype
local Dog = setmetatable({}, { __index = Animal })
Dog.__index = Dog

function Dog:new(name, breed)
    local instance = Animal.new(self, name)
    instance.breed = breed
    return instance
end

function Dog:speak()
    return self.name .. " barks."
end

-- Usage
local d = Dog:new("Rex", "German Shepherd")
print(d:speak()) -- Output: Rex barks.

In this structure:

  1. d delegates missing keys to Dog.
  2. Dog delegates missing keys to Animal.
  3. If a method like speak is defined on Dog, it shadows the version on Animal, providing method overriding and polymorphism.
