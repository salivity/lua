C Function to Create a Lua Execution State

In the Lua C API, creating an execution state is the foundational step required to embed the Lua interpreter within a C or C++ application. This article explains the primary C functions used to initialize a new state—specifically lua_newstate and its standard wrapper luaL_newstate—along with their parameters, memory management considerations, and proper cleanup procedures.

The Primary Function: lua_newstate

The core C API function used to create a new, independent Lua execution state is lua_newstate. Its function prototype is defined in lua.h:

lua_State *lua_newstate (lua_Alloc f, void *ud);

lua_newstate allocates and initializes a completely isolated Lua environment, returning a pointer to a lua_State object. It requires two arguments to manage memory:

  • f: A custom memory-allocation function adhering to the lua_Alloc prototype (void * (*lua_Alloc) (void *ud, void *ptr, size_t osize, size_t nsize)).
  • ud: An opaque pointer to user data that Lua passes to the allocator function on every invocation.

If memory allocation fails during state creation, lua_newstate returns NULL.

The Auxiliary Alternative: luaL_newstate

For applications that do not require custom memory managers, the Lua auxiliary library provides luaL_newstate, defined in lauxlib.h:

lua_State *luaL_newstate (void);

luaL_newstate requires no arguments. It internally invokes lua_newstate using a built-in allocator based on the standard C realloc function. This is the most frequently used function for general-purpose Lua embedding.

Closing the State

Every state created with either lua_newstate or luaL_newstate must eventually be released using lua_close:

void lua_close (lua_State *L);

Calling lua_close frees all dynamic memory, garbage-collects all objects, and terminates all active threads within that execution state.

Basic Implementation Example

The following code illustrates the standard workflow for initializing and releasing a Lua state in C:

#include <lua.h>
#include <lauxlib.h>
#include <lualib.h>
#include <stdio.h>

int main(void) {
    // Create a new execution state using the auxiliary library
    lua_State *L = luaL_newstate();
    if (L == NULL) {
        fprintf(stderr, "Failed to create Lua execution state.\n");
        return 1;
    }

    // Open standard Lua libraries (optional)
    luaL_openlibs(L);

    // Execute Lua code
    luaL_dostring(L, "print('Lua state created successfully.')");

    // Clean up and release the state
    lua_close(L);
    return 0;
}
