Lua Coroutines Producer Consumer Channels

This article explores how to implement cooperative producer-consumer patterns in Lua using coroutines as lightweight communication channels. By relying on cooperative multitasking rather than OS-level threads, Lua allows data to be yielded and resumed seamlessly between components without the overhead of locks, race conditions, or complex synchronization primitives. Readers will learn the mechanics of coroutine data passing, how to build demand-driven pipelines, and how to implement two-way communication channels.

The Mechanics of Data Transfer

In Lua, coroutines do not run concurrently in parallel; instead, they pass control explicitly. Communication happens at the synchronization boundary defined by coroutine.resume and coroutine.yield:

  • Values passed into coroutine.resume(co, ...) are received by the coroutine as parameters to its main function (on initial start) or as return values of the previous coroutine.yield() call.
  • Values passed to coroutine.yield(...) are returned to the caller by coroutine.resume.

This bidirectional exchange turns a coroutine into a synchronous data channel.

Demand-Driven (Consumer-Led) Implementation

The most idiomatic way to implement a producer-consumer relationship in Lua is demand-driven. The consumer asks for data, prompting the producer to execute until it generates a value, at which point it yields control back.

-- Producer: Generates values and yields them
local function create_producer(limit)
    return coroutine.create(function()
        for i = 1, limit do
            coroutine.yield(i)
        end
    end)
end

-- Consumer: Drives execution by resuming the producer
local function consumer(producer)
    while coroutine.status(producer) ~= "dead" do
        local success, value = coroutine.resume(producer)
        if success and value then
            print("Consumed:", value)
        end
    end
end

local channel = create_producer(5)
consumer(channel)

In this pattern, the producer pauses its execution state immediately after yielding, preserving its local variables and instruction pointer until the consumer requests the next item.

Idiomatic Iterators Using coroutine.wrap

Lua provides coroutine.wrap, which returns a function that resumes the coroutine directly instead of returning a status code. This allows producers to act directly as Lua iterator functions compatible with for loops:

local function producer(max)
    return coroutine.wrap(function()
        for i = 1, max do
            coroutine.yield(i * 10)
        end
    end)
end

-- The consumer is simply a generic for loop
for value in producer(3) do
    print("Received:", value)
end

Chaining Channels with Filters

Producers and consumers can be extended into pipelines using filters. A filter acts as both a consumer of an upstream coroutine and a producer for a downstream consumer:

local function source(n)
    return coroutine.wrap(function()
        for i = 1, n do
            coroutine.yield(i)
        end
    end)
end

local function filter(upstream)
    return coroutine.wrap(function()
        for val in upstream do
            -- Transform data and yield to next stage
            coroutine.yield(val * 2)
        end
    end)
end

local function sink(upstream)
    for val in upstream do
        print("Sink output:", val)
    end
end

-- Pipeline: source -> filter -> sink
sink(filter(source(4)))

Two-Way Channel Communication

Channels can also pass messages back to the producer during execution. When the consumer calls coroutine.resume(co, message), that message becomes the return value of the internal coroutine.yield() expression.

local function interactive_producer()
    return coroutine.create(function()
        local command = coroutine.yield("READY")
        while command ~= "STOP" do
            if command == "PING" then
                command = coroutine.yield("PONG")
            else
                command = coroutine.yield("UNKNOWN")
            end
        end
    end)
end

local co = interactive_producer()

-- Start the coroutine to reach the first yield
local _, response = coroutine.resume(co)
print("Initial:", response) -- READY

_, response = coroutine.resume(co, "PING")
print("Response:", response) -- PONG

_, response = coroutine.resume(co, "FOO")
print("Response:", response) -- UNKNOWN

coroutine.resume(co, "STOP")
print("Status:", coroutine.status(co)) -- dead

Using these mechanisms, Lua coroutines provide a deterministic, zero-allocation way to stream data between cooperative producers and consumers.
