How Fennel Brings Lisp Syntax to Lua

Fennel is a programming language that brings the power, expressiveness, and metaprogramming capabilities of Lisp to the Lua runtime with zero overhead. It achieves this by acting as a direct syntactic front-end that parses S-expressions and compiles them straight into clean, idiomatic Lua source code or bytecode. This article explains the technical mechanisms behind Fennel, including how its reader maps Lisp forms to Lua abstract syntax trees, its compile-time macro engine, and how it maintains seamless bidirectional compatibility with the broader Lua ecosystem.

Direct AST Mapping Without a Virtual Machine

Unlike languages that package an entire custom runtime, garbage collector, or virtual machine, Fennel does not run inside its own environment. Instead, Fennel is an ahead-of-time (or just-in-time via an embedded compiler) transpiler that targets the Lua VM directly.

When Fennel reads code, it translates S-expressions into an internal Abstract Syntax Tree (AST) that corresponds directly to Lua semantics:

  • Function Calls: A list form like (print "Hello") compiles directly to print("Hello").
  • Assignments: Forms like (local x 10) or (set x 20) compile to local x = 10 and x = 20.
  • Control Flow: Conditionals like (if condition then-branch else-branch) map directly to Lua's if ... then ... else ... end constructs or ternary-style expressions depending on context.

Because Lua makes a strict distinction between statements and expressions, Fennel’s compiler automatically detects whether an S-expression is situated in an expression context or a statement context. If an expression context requires a statement, Fennel generates an immediately invoked function expression (IIFE) behind the scenes to preserve pure expression-based Lisp semantics.

Native Data Structure Parity

Fennel relies entirely on Lua's native types for its data representations, avoiding any translation penalties at runtime:

  • Tables: Sequential tables (lists/arrays) are defined using square brackets [1 2 3], while associative tables (dictionaries/hash maps) use curly braces {:key "value"}. Both compile directly into Lua table literals.
  • Lists: Parentheses (...) represent code lists to be evaluated as function calls, special forms, or macro invocations.
  • Values: Numbers, booleans, and strings match Lua primitives exactly. nil in Fennel compiles directly to nil in Lua.

By aligning its syntax with Lua's underlying table implementation, Fennel inherits Lua's memory model, including 1-based array indexing and reference semantics, without introducing wrapper objects.

Zero-Overhead Compile-Time Macros

The primary advantage of using a Lisp syntax over standard Lua is the macro system. Fennel executes macros entirely during the compilation phase, meaning advanced abstractions add zero performance cost to the compiled Lua output.

Macros in Fennel are functions written in Fennel itself that take code forms as inputs and return new code forms. During compilation:

  1. The compiler encounters a macro definition or call.
  2. It executes the macro function using an internal Lua instance.
  3. The resulting AST replaces the macro invocation.
  4. The final, expanded AST is emitted as standard Lua code.

This architecture enables developers to build custom control structures, pattern matching, compile-time assertions, and domain-specific languages that resolve entirely before runtime.

Seamless Bidirectional Interoperability

Fennel is designed to be completely compatible with the existing Lua ecosystem, including LuaJIT, Neovim configurations, and game engines like LÖVE.

Because the compiler emits standard Lua, any existing Lua library can be imported using Fennel's (require :module-name) without foreign function interfaces (FFI) or translation layers. Conversely, standard Lua applications can load the Fennel compiler as a module, allowing Lua programs to require .fnl files directly via custom searchers. Variables, metatables, and object-oriented patterns defined in Lua can be inspected, called, and extended within Fennel with native speed.
