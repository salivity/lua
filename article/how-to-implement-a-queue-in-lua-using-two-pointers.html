How to Implement a Queue in Lua Using Two Pointers

This article explains how to efficiently implement a First-In, First-Out (FIFO) queue data structure in Lua using a single table and two integer pointers. Standard Lua table insertions and removals at the front of an array require shifting all remaining elements, resulting in an expensive \(O(n)\) time complexity. By maintaining dedicated first and last index pointers, both enqueue and dequeue operations can be executed in constant \(O(1)\) time.

The Problem with Default Tables

In Lua, calling table.remove(queue, 1) shifts every subsequent element down by one index. In high-throughput systems or large data sets, this overhead degrades performance. A two-pointer approach avoids this shifting by leaving processed slots empty (set to nil for garbage collection) and moving the starting index forward.

Core Mechanics

A two-pointer queue relies on three components:

  1. The Storage Table: Holds the queued elements.
  2. The first Pointer: Tracks the index of the next element to remove (the front of the queue).
  3. The last Pointer: Tracks the index of the most recently added element (the back of the queue).

When first > last, the queue is empty.

The Implementation

Below is a complete, object-oriented implementation of a queue using metatables:

local Queue = {}
Queue.__index = Queue

function Queue.new()
    return setmetatable({
        first = 1,
        last = 0,
        data = {}
    }, Queue)
end

function Queue:push(value)
    self.last = self.last + 1
    self.data[self.last] = value
end

function Queue:pop()
    if self:isEmpty() then
        return nil, "Queue is empty"
    end
    
    local value = self.data[self.first]
    self.data[self.first] = nil -- Free memory for garbage collection
    self.first = self.first + 1
    
    -- Optional reset to keep indices small when empty
    if self:isEmpty() then
        self.first = 1
        self.last = 0
    end
    
    return value
end

function Queue:peek()
    if self:isEmpty() then
        return nil
    end
    return self.data[self.first]
end

function Queue:isEmpty()
    return self.first > self.last
end

function Queue:length()
    return self.last - self.first + 1
end

Explanation of Operations

  • push(value): Increments self.last by 1 and assigns the new item to self.data[self.last]. This is strictly \(O(1)\).
  • pop(): Checks if self.first > self.last. If valid, it reads self.data[self.first], assigns nil to that index so Lua's garbage collector can reclaim the memory, and increments self.first.
  • Pointer Reset: When the queue becomes completely empty after a pop, resetting first to 1 and last to 0 prevents integer indices from growing indefinitely during long application lifecycles.
  • length(): Computed instantly using self.last - self.first + 1 rather than iterating through the table.

Usage Example

local q = Queue.new()

-- Enqueue items
q:push("Task A")
q:push("Task B")
q:push("Task C")

print("Queue size:", q:length()) -- Output: 3
print("Front element:", q:peek()) -- Output: Task A

-- Dequeue items
print("Processed:", q:pop()) -- Output: Task A
print("Processed:", q:pop()) -- Output: Task B

print("Remaining size:", q:length()) -- Output: 1
