Lua math.sin: Converting Degrees and Radians

In the Lua programming language, standard trigonometric functions like math.sin, math.cos, and math.tan calculate angles using radians rather than degrees. Because human input and game design often rely on degrees, working with these functions requires converting values between degrees and radians. This guide explains how Lua handles angular units, how the standard library performs these conversions, and how to properly pass degree values into math.sin and related functions.

Radians as the Default Standard

Lua's math library wraps the standard C mathematical library. Consequently, all forward trigonometric functions (math.sin, math.cos, math.tan) expect arguments expressed in radians. Similarly, inverse trigonometric functions (math.asin, math.acos, math.atan) return values measured in radians.

Passing a degree value directly into math.sin produces incorrect results. For example, math.sin(90) does not return 1, because Lua interprets 90 as 90 radians rather than a 90-degree right angle.

Converting Degrees to Radians

To use degree values with math.sin, you must first convert degrees to radians. Lua provides a built-in function, math.rad, specifically for this purpose.

local degrees = 90
local radians = math.rad(degrees)
local result = math.sin(radians)

print(result) -- Output: 1.0

Alternatively, you can write the conversion directly into the function call:

local result = math.sin(math.rad(90))

Under the hood, math.rad(d) multiplies the degree value by \(\pi / 180\). If you prefer manual conversion or need to avoid a function call overhead in performance-critical loops, compute it using math.pi:

local deg2rad = math.pi / 180
local result = math.sin(90 * deg2rad)

Converting Radians to Degrees

When working with inverse functions like math.asin, the returned value is in radians. To display or process this value in degrees, use math.deg.

local radValue = math.asin(1.0) -- Returns pi / 2 radians
local degValue = math.deg(radValue)

print(degValue) -- Output: 90.0

The mathematical formula used by math.deg(r) multiplies the radian value by \(180 / \pi\):

local rad2deg = 180 / math.pi
local degValue = math.asin(1.0) * rad2deg

Summary of Related Trigonometric Functions

The degree-to-radian conversion workflow applies uniformly across all Lua trigonometric operations:

  • math.sin(math.rad(deg)): Sine of an angle in degrees.
  • math.cos(math.rad(deg)): Cosine of an angle in degrees.
  • math.tan(math.rad(deg)): Tangent of an angle in degrees.
  • math.deg(math.asin(x)): Inverse sine returning degrees.
  • math.deg(math.acos(x)): Inverse cosine returning degrees.
  • math.deg(math.atan(y, x)): Two-argument inverse tangent returning degrees.
