Lua Modulo Operator with Negative Floats

In the Lua programming language, the modulo operator (%) calculates the remainder of a division operation using floored division rather than truncated division. When applied to negative floating-point numbers, Lua defines the operation through the mathematical formula a % b = a - math.floor(a / b) * b. Because Lua relies on the floor function—which rounds down toward negative infinity—the result of the modulo operation consistently inherits the sign of the divisor (b), rather than the dividend (a). This behavior applies identically to both integers and standard floating-point values.

The Underlying Formula

Unlike languages such as C, C++, or Java that truncate division toward zero, Lua uses the floor division model. The operation a % b is strictly calculated as:

a % b == a - math.floor(a / b) * b

Because math.floor(x) always returns the largest integer less than or equal to x, fractional values and negative values change how the quotient is rounded, directly influencing the remainder.

The Sign Rule

The sign of the result is determined entirely by the sign of the second operand (the divisor b):

  • If b > 0: The result will always be non-negative, falling within the range [0, b).
  • If b < 0: The result will always be non-positive, falling within the range (b, 0].

The sign of a (the dividend) does not determine whether the final result is positive or negative.

Examples with Floating-Point Values

1. Negative Dividend, Positive Divisor (-a % b)

When dividing a negative float by a positive float, the result is positive.

local result = -7.5 % 2.0
print(result) -- Output: 0.5

Step-by-step breakdown:

  • -7.5 / 2.0 = -3.75
  • math.floor(-3.75) = -4
  • -7.5 - (-4 * 2.0) = -7.5 - (-8.0) = 0.5

2. Positive Dividend, Negative Divisor (a % -b)

When dividing a positive float by a negative float, the result is negative.

local result = 7.5 % -2.0
print(result) -- Output: -0.5

Step-by-step breakdown:

  • 7.5 / -2.0 = -3.75
  • math.floor(-3.75) = -4
  • 7.5 - (-4 * -2.0) = 7.5 - 8.0 = -0.5

3. Negative Dividend, Negative Divisor (-a % -b)

When both operands are negative, the quotient is positive, and the remainder retains the negative sign of the divisor.

local result = -7.5 % -2.0
print(result) -- Output: -1.5

Step-by-step breakdown:

  • -7.5 / -2.0 = 3.75
  • math.floor(3.75) = 3
  • -7.5 - (3 * -2.0) = -7.5 - (-6.0) = -1.5

Practical Implications

Because x % 1.0 returns the fractional part of a number, passing a negative float like -3.25 % 1.0 yields 0.75 instead of -0.25. This behavior ensures smooth wrapping for cyclical data structures, angle normalization (such as keeping degrees between 0 and 360), and coordinate wrapping in continuous spaces without requiring manual checks for negative values.
