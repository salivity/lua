How to Use string.gsub with Tables and Captures in Lua

In Lua, the string.gsub function is a versatile tool for pattern matching and global string substitution. While it commonly replaces text using static strings, it also accepts tables as replacement values, mapping matched text or explicit capture groups directly to key-value pairs. This article explains the underlying mechanism of how string.gsub handles capture groups when paired with replacement tables, including lookup rules, fallback behaviors, and code examples.

The Mechanics of string.gsub

The basic syntax of the function is:

string.gsub(s, pattern, repl [, n])
  • s: The source string.
  • pattern: The pattern to search for, which may contain parentheses to define captures.
  • repl: The replacement specification, which can be a string, a function, or a table.
  • n (optional): The maximum number of substitutions to perform.

When repl is a table, string.gsub performs a lookup for every match found by pattern, using matched elements as keys to retrieve replacement values.

How Replacement Tables Work Without Captures

If the pattern contains no capture groups (no parentheses), string.gsub uses the entire matched substring as the table key.

local dictionary = {
    cat = "feline",
    dog = "canine"
}

local text = "The cat chased the dog."
local result = string.gsub(text, "%a+", dictionary)

print(result)
-- Output: The feline chased the canine.

Key behavior:

  • For "cat", dictionary["cat"] returns "feline", so "cat" is replaced.
  • For "The", dictionary["The"] returns nil. When a key is missing or evaluates to nil or false, string.gsub leaves the original matched substring unchanged.

How Capture Groups Interact with Replacement Tables

When parentheses are added to a pattern, Lua creates capture groups. When using a table as the replacement parameter, only the first capture group is used as the lookup key, regardless of how many capture groups are defined.

1. Isolating the Key with a Single Capture

Captures allow you to match a broader context while using only a specific portion of the match as the table key:

local vars = {
    user = "Alice",
    role = "Admin"
}

local template = "Hello, $user! Your role is $role."
-- Match '$' followed by alphanumeric characters, capturing only the name
local result = string.gsub(template, "%$(%w+)", vars)

print(result)
-- Output: Hello, Alice! Your role is Admin.

In this example:

  • The pattern %$%w+ matches $user.
  • The capture group (%w+) isolates user.
  • string.gsub looks up vars["user"], which yields "Alice".
  • The entire matched portion ($user) is replaced by "Alice".

2. Behavior with Multiple Captures

If a pattern defines multiple capture groups, string.gsub ignores all captures after the first when performing a table lookup.

local map = {
    X = "Success"
}

local text = "Key: X=100"
-- Two captures: (%a) and (%d+)
local result = string.gsub(text, "(%a)=(%d+)", map)

print(result)
-- Output: Key: Success

Even though both (%a) and (%d+) are captured, only the value of the first capture ("X") is passed to map. The entire match ("X=100") is replaced with the value of map["X"].

Handling Missing Keys and Non-String Values

When string.gsub resolves a table lookup:

  • String or Number: If the value at table[key] is a string or a number, that value replaces the match.
  • Nil or False: If table[key] is nil or false, the match is not replaced, and the original text remains intact.
  • Other Types: If table[key] is any other type (such as a boolean true, another table, or a thread), Lua throws a runtime error stating that the replacement is an invalid type.
