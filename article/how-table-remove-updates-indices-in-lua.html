How table.remove Updates Indices in Lua

In the Lua programming language, the table.remove function eliminates an element from an array-like sequence and automatically shifts all subsequent elements to the left by one position to fill the gap. By systematically copying list[i + 1] to list[i] for every index following the target position and setting the final index to nil, Lua preserves a contiguous sequence without holes, ensuring the length operator (#) remains accurate and reliable.

The Removal and Index-Shifting Mechanism

The standard library function follows the signature table.remove(list [, pos]). When invoked, it modifies the sequence through the following steps:

  1. Target Validation: If no index pos is provided, it defaults to the length of the list (#list). If pos is provided, it must fall within the range 1 <= pos <= #list (or #list + 1 for empty tables).

  2. Value Stash: The function captures the value at list[pos] so it can be returned when the operation completes.

  3. Element Shifting: When pos is less than #list, Lua iterates from pos up to #list - 1. During each iteration, it performs the assignment:

    list[i] = list[i + 1]

    This effectively moves every subsequent element down by one sequential index.

  4. Clearing the Tail: After shifting the elements, the original last element at list[#list] is explicitly set to nil. This step deletes the redundant reference, shrinks the internal array size, and ensures garbage collection can reclaim the removed reference if applicable.

  5. Return Value: The function returns the stashed value.

Example

Consider a sequence containing four strings:

local items = {"alpha", "beta", "gamma", "delta"}
local removed = table.remove(items, 2)

During this call:

  • The value "beta" at index 2 is stored to be returned.
  • The element at index 3 ("gamma") moves to index 2.
  • The element at index 4 ("delta") moves to index 3.
  • Index 4 is set to nil.

The resulting table is {"alpha", "gamma", "delta"}, with a new length of 3, and removed equals "beta".

Performance Implications

Because Lua must shift every subsequent element when removing from the beginning or middle of a table, the time complexity of table.remove is \(O(n - pos)\), where \(n\) is the length of the sequence.

  • Removing from the end (table.remove(list)): Operates in \(O(1)\) time because no elements require shifting; Lua only needs to set list[n] = nil.
  • Removing from the beginning (table.remove(list, 1)): Operates in \(O(n)\) time because every single element in the sequence must be reassigned to the preceding index.
