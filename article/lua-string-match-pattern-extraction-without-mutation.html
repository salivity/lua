Lua string.match: Pattern Extraction Without Mutation

In the Lua programming language, the string.match function extracts substrings by scanning an input string against a specified pattern and returning the matched segments without altering the original source data. This non-destructive behavior is rooted in Lua's core architecture, where all strings are strictly immutable and pattern operations are read-only. This article explains the internal mechanics of string.match, how it identifies and retrieves captured patterns, and why the source data is guaranteed to remain untouched throughout the extraction process.

String Immutability in Lua

To understand why string.match does not modify source data, one must understand how Lua handles strings. In Lua, strings are immutable values and are interned into a central hash table. Once a string is created, its byte sequence cannot be modified, resized, or overwritten in place by any standard library function. Whenever a function appears to change a string, it actually constructs an entirely new string in memory and returns a reference to that new object. Because the underlying memory of the source string cannot be written to, operations like string.match are structurally incapable of mutating their input.

The Mechanics of string.match

The string.match function takes a source string, a pattern, and an optional starting position index:

string.match(s, pattern [, init])

When invoked, the Lua runtime executes the following sequence:

  1. Read-Only Traversal: Lua's pattern-matching engine receives a pointer to the source string's byte buffer. Starting from index init (defaulting to 1), the engine advances through the string byte-by-byte, evaluating the rules defined in the pattern. It merely reads and compares characters; it never writes to the buffer.
  2. State Tracking: The engine maintains internal state offsets indicating where a match begins and ends, as well as the boundaries of any capture groups defined by parentheses ().
  3. Extraction and Allocation: Once a match succeeds:
    • If the pattern contains captures, string.match copies the byte sequences corresponding to each capture group and instantiates them as new Lua strings.
    • If the pattern contains no captures, it copies the entire matched span and instantiates that as a single new Lua string.
  4. Return Execution: The function returns the newly allocated string(s) to the caller. If no match is found, the function returns nil without allocating new string objects.

Pattern Extraction in Practice

Consider extracting components from a structured string:

local source = "Status: 200 OK"
local code, message = string.match(source, "(%d+)%s+(%a+)")

print(code)    -- Output: 200
print(message) -- Output: OK
print(source)  -- Output: Status: 200 OK

During this operation, the variable source remains intact. The variables code and message receive references to brand-new string objects created from the matched byte spans (200 and OK). The original variable retains its exact identity and memory address, guaranteeing zero side effects on the source data.
