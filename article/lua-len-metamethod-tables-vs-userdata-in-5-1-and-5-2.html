Lua __len Metamethod: Tables vs Userdata in 5.1 and 5.2

The handling of the length operator (#) and the __len metamethod represents one of the most significant semantic differences between Lua 5.1 and Lua 5.2. While Lua 5.1 strictly restricts custom length operations to userdata types, Lua 5.2 expands this capability to standard tables, fundamentally changing how custom container types, proxies, and array wrappers can be implemented.

Behavior in Lua 5.1

In Lua 5.1, the __len metamethod only functions on userdata. If you assign a metatable containing a __len metamethod to a full or light userdata value, invoking # on that value will correctly trigger the metamethod function and return its result. If no metamethod is defined, calling # on a userdata object raises an error indicating an attempt to get the length of a userdata value.

Conversely, Lua 5.1 completely ignores __len on tables. The # operator on a table always executes the built-in raw boundary search algorithm, looking for an integer key n such that t[n] is non-nil and t[n+1] is nil. Because standard Lua 5.1 hardcodes this behavior in the VM for performance reasons, developers cannot override the length operator to create virtual arrays, sparse arrays, or read-only proxy tables using pure Lua.

Behavior in Lua 5.2

Lua 5.2 harmonizes this behavior by extending __len support to tables. When the # operator is applied to a table, Lua checks whether the table has a metatable with a __len field:

  • If __len is defined (whether as a function or a value with a __call metamethod), Lua calls it with the table as the argument and returns the result.
  • If __len is not defined, Lua falls back to the standard raw length calculation used in version 5.1.

For userdata, the behavior remains unchanged from Lua 5.1: Lua consults the metatable's __len field and executes it, raising an error if it is not present.

Because tables could now override the # operator, Lua 5.2 also introduced the rawlen(v) standard function. rawlen returns the primitive length of a table or string without invoking any metamethods, functioning as the length equivalent of rawget and rawset.

Summary Comparison

  • Userdata in Lua 5.1: Honors __len.
  • Userdata in Lua 5.2: Honors __len.
  • Tables in Lua 5.1: Ignores __len; # always calculates raw array size.
  • Tables in Lua 5.2: Honors __len; falls back to raw array size only when omitted, with rawlen available for bypassing the metamethod.
