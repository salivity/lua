Handling Unicode in Lua with the utf8 Library

The Lua programming language treats strings as arbitrary byte sequences by default, which historically made multi-byte character processing difficult. Introduced in Lua 5.3, the standard utf8 library provides lightweight, built-in functionality to bridge this gap, enabling developers to validate UTF-8 encodings, convert between Unicode code points and byte sequences, determine character counts, and iterate over characters within UTF-8 strings.

Converting Code Points to UTF-8 Sequences (utf8.char)

The utf8.char function accepts zero or more integer code points and converts them into a valid UTF-8 string. It acts as the Unicode-aware counterpart to string.char.

local str = utf8.char(0x1F600, 0x41) -- Produces a grinning face emoji followed by 'A'

If an argument is an invalid Unicode code point, the function raises an error.

Extracting Code Points from Strings (utf8.codepoint)

The utf8.codepoint function performs the reverse of utf8.char. It accepts a string and returns the numerical code points as integers.

local cp1, cp2 = utf8.codepoint("Lua", 1, 2) -- Returns 76, 117

You can supply optional byte offsets i and j to specify the slice of the string to examine. If the target substring contains an invalid UTF-8 byte sequence, an error is raised.

Counting Characters vs. Bytes (utf8.len)

Because Unicode characters can span anywhere from 1 to 4 bytes in UTF-8, standard length operators (#str) only return the raw byte count. The utf8.len function calculates the actual number of UTF-8 characters within a given byte range.

local text = "Olá"
print(#text)          -- 4 (bytes)
print(utf8.len(text)) -- 3 (characters)

In addition to counting, utf8.len serves as a validator. If it encounters an invalid UTF-8 sequence, it returns false (or nil in earlier Lua 5.3 releases) alongside the byte index of the first invalid byte.

Iterating Over Characters (utf8.codes)

Iterating through a UTF-8 string by byte index can break multi-byte characters. The utf8.codes function provides a stateful iterator for for loops, returning both the byte offset and the code point for each character in the string.

for position, code in utf8.codes("Café") do
    print(position, code)
end

Translating Character Positions to Byte Offsets (utf8.offset)

The utf8.offset function translates relative character positions into raw byte indices. Given a string and a character index n, it returns the byte offset where that character begins.

local text = "Привет"
local byte_index = utf8.offset(text, 3) -- Finds the starting byte of the 3rd character

A negative index counts backward from the end of the string. This utility is critical for safely slicing and manipulating strings using standard Lua functions like string.sub.

Pattern Matching with utf8.charpattern

The library provides the constant string pattern utf8.charpattern. This pattern strictly matches exactly one UTF-8 byte sequence (1 to 4 bytes). It integrates directly with Lua's pattern-matching functions to tokenize text character-by-character.

for char in string.gmatch("Hello, 世界", utf8.charpattern) do
    -- Yields each individual UTF-8 character as a string
end

Scope and Limitations

The utf8 library focuses strictly on byte-to-codepoint encoding, validation, and traversal. To keep the Lua runtime small and dependency-free, it does not include Unicode character property tables. As a result, it does not provide case-folding (upper/lowercase conversion), collation, normalization, or grapheme cluster segmentation.
