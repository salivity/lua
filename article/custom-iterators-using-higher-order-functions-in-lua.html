Custom Iterators Using Higher-Order Functions in Lua

This article explains how to build custom iterators in Lua using higher-order functions and closures. Readers will learn the mechanics behind Lua's generic for loop, how to write iterator factories that capture state using upvalues, and how to construct functional iterator combinators such as filters and mappers to manipulate sequences efficiently.

Understanding Lua's Generic for Loop

In Lua, an iterator is simply a function that returns the next element in a sequence every time it is invoked. When the sequence is exhausted, the iterator returns nil.

Lua's generic for loop syntax expects an iterator function, an invariant state, and an initial value for the first variable:

for var_1, ..., var_n in explist do
    block
end

When using higher-order functions, the explist typically calls a "factory" function. This factory returns a closure—a function bundled with references to its surrounding lexical environment (upvalues)—which acts as the iterator.

Building a Basic Closure-Based Iterator

A higher-order function is a function that takes one or more functions as arguments, returns a function, or both. In Lua iterator design, the factory function is the higher-order function that generates and returns the actual iterator.

Consider a simple custom range iterator:

local function range(start, stop, step)
    step = step or 1
    local current = start - step

    -- The returned function is a closure capturing current, stop, and step
    return function()
        current = current + step
        if current <= stop then
            return current
        end
        return nil
    end
end

To consume this iterator:

for num in range(1, 10, 2) do
    print(num) -- Outputs: 1, 3, 5, 7, 9
end

In this implementation, range acts as the factory. The internal state (current, stop, step) is preserved between iterations via lexical scoping, eliminating the need to manage external variables.

Iterating Over Custom Collections

Higher-order iterator factories can traverse non-standard data structures, such as linked lists or reverse arrays, while keeping collection internals private.

Here is an iterator factory that iterates over an array in reverse:

local function reverse_each(tbl)
    local index = #tbl + 1

    return function()
        index = index - 1
        if index > 0 then
            return index, tbl[index]
        end
    end
end

local fruits = {"apple", "banana", "cherry"}

for index, value in reverse_each(fruits) do
    print(index, value)
end

Composing Iterators with Higher-Order Combinators

Because Lua treats functions as first-class citizens, you can write higher-order functions that take an existing iterator and return a modified iterator. This enables functional transformations like filtering and mapping.

1. The filter Combinator

The following filter function accepts an iterator factory and a predicate function, returning a new iterator that skips non-matching elements:

local function filter(iterator_factory, predicate)
    return function(...)
        local iter = iterator_factory(...)
        return function()
            while true do
                local val = iter()
                if val == nil then
                    return nil
                end
                if predicate(val) then
                    return val
                end
            end
        end
    end
end

Usage:

local is_even = function(x) return x % 2 == 0 end
local even_range = filter(range, is_even)

for num in even_range(1, 10) do
    print(num) -- Outputs: 2, 4, 6, 8, 10
end

2. The map Combinator

The map combinator transforms elements produced by an iterator using a transformation function:

local function map(iterator_factory, transform)
    return function(...)
        local iter = iterator_factory(...)
        return function()
            local val = iter()
            if val ~= nil then
                return transform(val)
            end
            return nil
        end
    end
end

Usage:

local square = function(x) return x * x end
local squared_range = map(range, square)

for num in squared_range(1, 5) do
    print(num) -- Outputs: 1, 4, 9, 16, 25
end

Performance Considerations

While closure-based iterators constructed via higher-order functions are expressive, creating a closure allocates a new table/object in memory. For tight, performance-critical loops where garbage collection overhead must be minimized, consider using Lua's stateless iterator pattern (which passes invariant state and loop variables directly to the for loop). However, for general application logic and functional pipeline patterns, higher-order closure iterators provide clean encapsulation and modularity.
