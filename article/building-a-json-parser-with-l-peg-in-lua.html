Building a JSON Parser with LPeg in Lua

This article demonstrates how to construct a complete, standards-compliant JSON parser using Lua and the LPeg (Parsing Expression Grammar) library. By leveraging LPeg’s pattern composition, substitution captures, and fold captures, you can build a parser that translates JSON strings, numbers, booleans, nulls, arrays, and objects directly into native Lua data structures with minimal code and high performance.

Prerequisites and Setup

To follow this implementation, you need the lpeg library installed in your Lua environment. Import the LPeg module and alias its primary functions for readability:

local lpeg = require("lpeg")
local P, R, S, V = lpeg.P, lpeg.R, lpeg.S, lpeg.V
local C, Cs, Ct, Cf, Cc, Cg = lpeg.C, lpeg.Cs, lpeg.Ct, lpeg.Cf, lpeg.Cc, lpeg.Cg

Handling Whitespace

JSON allows insignificant whitespace around structural tokens. Define a pattern to consume whitespace characters:

local space = S(" \t\r\n")^0
local function token(p)
    return p * space
end

Parsing Literals and Numbers

JSON primitives include booleans, null, and numbers. In Lua, JSON null can be represented as a sentinel table to distinguish it from a missing key, or simply mapped to a unique object.

local null = token(P("null")) * Cc(setmetatable({}, { __tostring = function() return "null" end }))
local true_val = token(P("true")) * Cc(true)
local false_val = token(P("false")) * Cc(false)

-- Numbers (RFC 8259 specification)
local digit = R("09")
local hex = R("09", "af", "AF")
local sign = S("+-")^-1
local int = sign * (P("0") + (R("19") * digit^0))
local frac = P(".") * digit^1
local exp = S("eE") * sign * digit^1
local number = token(C(int * frac^-1 * exp^-1)) / tonumber

Parsing Strings and Escapes

JSON strings are enclosed in double quotes and support escape sequences such as \", \\, and \uXXXX unicode sequences. The Cs (substitution capture) function simplifies transforming escaped sequences into their corresponding characters:

local escape_map = {
    ['"'] = '"',
    ['\\'] = '\\',
    ['/'] = '/',
    ['b'] = '\b',
    ['f'] = '\f',
    ['n'] = '\n',
    ['r'] = '\r',
    ['t'] = '\t'
}

local escaped_char = P('\\') * (
    S('"\\/bfnrt') / escape_map +
    P("u") * C(hex * hex * hex * hex) / function(h)
        local code = tonumber(h, 16)
        if utf8 and utf8.char then
            return utf8.char(code)
        elseif code < 128 then
            return string.char(code)
        else
            return "?" -- Fallback if utf8 library is unavailable
        end
    end
)

local regular_char = C(P(1) - S('"\\\r\n'))
local string_content = Cs((escaped_char + regular_char)^0)
local json_string = token(P('"') * string_content * P('"'))

Constructing the Grammar

JSON contains recursive structures: arrays and objects can contain arbitrary JSON values. Define the structural rules within an LPeg grammar table using lpeg.V:

local comma = token(P(","))
local colon = token(P(":"))
local open_brace = token(P("{"))
local close_brace = token(P("}"))
local open_bracket = token(P("["))
local close_bracket = token(P("]"))

local json_grammar = P{
    "VALUE",
    VALUE = space * (
        json_string +
        number +
        V("OBJECT") +
        V("ARRAY") +
        true_val +
        false_val +
        null
    ),

    -- Array: collects values into a Lua sequence table using Ct
    ARRAY = open_bracket * Ct(
        (V("VALUE") * (comma * V("VALUE"))^0)^-1
    ) * close_bracket,

    -- Object: pairs are folded into a single table using Cf
    PAIR = Cg(json_string * colon * V("VALUE")),
    OBJECT = open_brace * Cf(
        Ct(true) * (V("PAIR") * (comma * V("PAIR"))^0)^-1,
        rawset
    ) * close_brace
}

local parser = json_grammar * -P(1)

Exposing the Parse Interface

Wrap the compiled pattern into a callable function that returns the decoded data or an error message:

local function decode(json_str)
    if type(json_str) ~= "string" then
        return nil, "Argument must be a string"
    end
    local result = parser:match(json_str)
    if result == nil then
        return nil, "Syntax error in JSON string"
    end
    return result
end

Complete Example

local sample = [[
{
    "title": "LPeg JSON Parser",
    "version": 1.0,
    "completed": true,
    "tags": ["lua", "parsing", "lpeg"],
    "details": {
        "nullField": null,
        "escape": "Line 1\nLine 2"
    }
}
]]

local data, err = decode(sample)
if not data then
    print("Error:", err)
else
    print("Decoded Title:", data.title)
    print("Tag Count:", #data.tags)
    print("Detail Escape:", data.details.escape)
end

This approach eliminates the need for a separate lexer pass, streaming the text directly into structured Lua tables and primitives with minimal memory overhead.
