Lua Integer Overflow and Two's Complement

This article examines how the Lua programming language handles integer overflow and whether it implements two's complement wrap-around arithmetic. Modern versions of Lua (specifically Lua 5.3 and later) feature a dedicated 64-bit signed integer subtype that explicitly supports wrap-around arithmetic using two's complement representation. Below is a detailed look at how this behavior operates, how to observe it, and the exceptions you should know.

Native Integer Support in Lua 5.3+

Prior to version 5.3, Lua represented all numbers as double-precision floating-point values by default. In Lua 5.3, the language introduced a dual-representation numeric system: standard 64-bit floating-point numbers (flt64) and standard 64-bit signed integers (int64).

Under standard builds, Lua integers are signed 64-bit values represented in two's complement form, spanning from math.mininteger (\(-2^{63}\)) to math.maxinteger (\(2^{63}-1\)).

Wrap-Around Behavior

Standard arithmetic operations on integers in Lua—such as addition, subtraction, and multiplication—are defined to wrap around modulo \(2^{64}\). Unlike languages like C, where signed integer overflow produces undefined behavior, Lua explicitly specifies two's complement wrap-around behavior for its signed integer arithmetic.

When an operation exceeds the upper limit of the integer range, it wraps around to the negative range:

local max = math.maxinteger
print(max)          -- 9223372036854775807
print(max + 1)      -- -9223372036854775808
print(max + 1 == math.mininteger) -- true

Similarly, underflowing below math.mininteger wraps back to positive values:

local min = math.mininteger
print(min)          -- -9223372036854775808
print(min - 1)      -- 9223372036854775807
print(min - 1 == math.maxinteger) -- true

Bitwise Operations

Lua also includes native bitwise operators (&, |, ~, >>, <<). Because these operators operate strictly on integers, they also respect the two's complement binary representation. For example, bitwise negation (~) on an integer flips all bits, adhering to two's complement rules:

print(~0)           -- -1
print(~1)           -- -2

Exceptions and Division

While addition, subtraction, and multiplication wrap around, division does not perform standard integer wrapping:

  1. Standard Division (/): Always promotes the operands to floating-point numbers, resulting in a float value even if the inputs are integers.
  2. Floor Division (//): Performs division and rounds the result toward negative infinity. Attempting to divide math.mininteger // -1 cannot be represented in a 64-bit signed integer and results in integer overflow wrapping back to math.mininteger.

In summary, Lua 5.3 and newer natively supports integer overflow wrapping using two's complement arithmetic across all primary integer operations.
