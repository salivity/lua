How to Pass Data to a Yielded Coroutine in Lua

In Lua, coroutines communicate bidirectionally with the main thread using coroutine.resume and coroutine.yield. While the initial call to coroutine.resume passes arguments to the coroutine's main function, subsequent calls pass extra arguments directly into the coroutine as the return values of coroutine.yield. This article explains the exact mechanics of passing data back into a suspended Lua coroutine with clear, practical examples.

The Mechanism of coroutine.yield Return Values

When a coroutine calls coroutine.yield(), its execution pauses immediately, and control returns to the caller of coroutine.resume. Any arguments passed to coroutine.yield(...) are returned by that coroutine.resume call (preceded by a true boolean indicating success).

To send data back into the coroutine, you supply additional arguments to the next coroutine.resume call. Inside the coroutine, coroutine.yield() evaluates directly to these provided values.

Code Demonstration

Consider the following example:

-- Create a coroutine
local co = coroutine.create(function(initial_msg)
    print("Coroutine started with:", initial_msg)
    
    -- Pause execution and send "need_data" to resume
    -- Execution halts here until resumed
    local received_value = coroutine.yield("need_data")
    
    -- When resumed, 'received_value' holds the data passed by resume
    print("Coroutine received:", received_value)
    
    return "done"
end)

-- 1. Start the coroutine
local success, response = coroutine.resume(co, "Hello")
print("Main thread got:", response)

-- 2. Resume the coroutine and pass data back into the yield
local success2, final_result = coroutine.resume(co, 42)
print("Main thread got:", final_result)

Execution Flow Step-by-Step

  1. Initial Resume: The main thread invokes coroutine.resume(co, "Hello"). The coroutine starts, receives "Hello" as initial_msg, and runs until it reaches coroutine.yield("need_data").
  2. First Yield: The coroutine pauses. coroutine.resume returns true (success) followed by "need_data". The main thread prints Main thread got: need_data.
  3. Subsequent Resume: The main thread invokes coroutine.resume(co, 42). The number 42 is passed back into the coroutine.
  4. Resuming from Yield: Inside the coroutine, the coroutine.yield("need_data") expression resolves to 42, assigning it to local received_value.
  5. Completion: The coroutine resumes execution, prints the received value, and terminates by returning "done", which is handed back to success2, final_result.

Passing Multiple Values

The exchange supports multiple arguments. When invoking coroutine.resume(co, val1, val2, val3), the corresponding yield unpacks all parameters:

local co = coroutine.create(function()
    local x, y, op = coroutine.yield()
    if op == "add" then
        return x + y
    end
end)

coroutine.resume(co) -- Move to the yield point
local ok, result = coroutine.resume(co, 10, 20, "add")
print(result) -- Output: 30

By assigning the result of coroutine.yield() to variables within the coroutine, you create a responsive input loop driven by external coroutine.resume calls.
