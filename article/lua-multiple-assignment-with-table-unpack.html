Lua Multiple Assignment with table.unpack

In the Lua programming language, multiple assignment allows you to bind several local variables at once using comma separation. When paired with table.unpack (or unpack in Lua 5.1), Lua takes the list of values returned by the function and maps them directly across the target variables from left to right. This mechanism provides a clean, idiomatic way to destructure arrays, though its behavior depends heavily on the count of variables and the position of the function call within the assignment statement.

Basic Comma Assignment Mechanics

In Lua, a multiple assignment statement evaluates all expressions on the right-hand side before assigning them to the variables on the left-hand side:

local a, b, c = 1, 2, 3

When you use table.unpack(list), the function returns all array elements as a multi-value result (a tuple-like return list). Lua places these values sequentially into the corresponding variables on the left:

local items = {"apple", "banana", "cherry"}
local first, second, third = table.unpack(items)

print(first)  -- Output: apple
print(second) -- Output: banana
print(third)  -- Output: cherry

Handling Mismatched Counts

Lua automatically adjusts multi-value returns to fit the number of variables on the left side of the assignment.

1. Excess Variables (Padding with nil)

If you provide more variables than the number of values returned by table.unpack, Lua assigns nil to the remaining variables:

local items = {10, 20}
local a, b, c, d = table.unpack(items)

print(a) -- Output: 10
print(b) -- Output: 20
print(c) -- Output: nil
print(d) -- Output: nil

2. Fewer Variables (Truncation)

If you provide fewer variables than there are values in the unpacked table, Lua assigns values up to the number of variables and silently discards the rest:

local items = {10, 20, 30, 40, 50}
local a, b = table.unpack(items)

print(a) -- Output: 10
print(b) -- Output: 20

The Last-Expression Rule

The most critical rule regarding table.unpack in comma assignments is its position on the right-hand side. Lua only expands a multi-value return to its full length if the function call is the last (or only) expression in the assignment list.

When unpack is Not the Last Expression

If table.unpack is followed by another value or expression, Lua truncates its return values to exactly one value:

local items = {"first", "second", "third"}
local a, b, c = table.unpack(items), "extra"

print(a) -- Output: first
print(b) -- Output: extra
print(c) -- Output: nil

Here, table.unpack(items) only supplies "first". The variable b receives "extra", and c receives nil.

When unpack is the Last Expression

If table.unpack is placed at the end of the expression list, it retains all its returned elements:

local items = {"second", "third"}
local a, b, c = "first", table.unpack(items)

print(a) -- Output: first
print(b) -- Output: second
print(c) -- Output: third

In this case, "first" maps to a, and the unpack result fills b and c without truncation.
