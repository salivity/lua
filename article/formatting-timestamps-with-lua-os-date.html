Formatting Timestamps with Lua os.date

In the Lua programming language, the os.date function is the primary tool for converting numeric timestamps into human-readable calendar representations or structured tables. This article explains how os.date processes dates and times, breaks down its syntax and control specifiers, and demonstrates how to output timestamps as custom strings, tables, or UTC-adjusted values.

The os.date Syntax

The function accepts two optional parameters:

os.date([format [, time]])
  • format: A string determining the output structure. If omitted, it defaults to "%c", which produces a localized date and time representation.
  • time: An integer representing epoch time (seconds since January 1, 1970). If omitted, it defaults to the current time returned by os.time().

String Formatting

Lua relies on the underlying C runtime library's strftime function to generate formatted strings. By combining standard conversion specifiers, you can build custom calendar formats such as ISO 8601 strings.

local current_time = os.time()

-- Formats to: YYYY-MM-DD HH:MM:SS
local formatted = os.date("%Y-%m-%d %H:%M:%S", current_time)
print(formatted) -- Output: 2026-03-31 14:30:15 (example)

Common format specifiers include:

  • %Y: Four-digit year (e.g., 2026)
  • %m: Two-digit month from 01 to 12
  • %d: Two-digit day of the month from 01 to 31
  • %H: Two-digit hour in 24-hour format (00 to 23)
  • %I: Two-digit hour in 12-hour format (01 to 12)
  • %M: Two-digit minute from 00 to 59
  • %S: Two-digit second from 00 to 59
  • %p: Meridian indicator (AM or PM)
  • %A / %a: Full or abbreviated weekday name (e.g., Tuesday / Tue)
  • %B / %b: Full or abbreviated month name (e.g., March / Mar)

Generating Structured Tables

Instead of a formatted string, os.date can return a key-value table containing the individual components of a timestamp. To do this, pass "*t" as the format parameter.

local date_table = os.date("*t", os.time())

print(date_table.year)  -- 4-digit year
print(date_table.month) -- 1 to 12
print(date_table.day)   -- 1 to 31
print(date_table.hour)  -- 0 to 23
print(date_table.min)   -- 0 to 59
print(date_table.sec)   -- 0 to 61
print(date_table.wday)  -- Weekday (1 is Sunday, 7 is Saturday)
print(date_table.yday)  -- Day of the year (1 to 366)
print(date_table.isdst) -- Boolean indicating Daylight Saving Time

This table format is directly compatible with os.time(), allowing you to manipulate individual date fields and convert the table back into an epoch timestamp.

Working with UTC (Coordinated Universal Time)

By default, os.date converts timestamps according to the host system's local time zone. To format the timestamp as UTC, prefix the format string with an exclamation mark (!):

-- UTC formatted string
local utc_string = os.date("!%Y-%m-%dT%H:%M:%SZ", os.time())
print(utc_string) -- e.g., 2026-03-31T18:30:15Z

-- UTC structured table
local utc_table = os.date("!*t", os.time())
print(utc_table.hour) -- UTC hour instead of local hour
