Lua -e Flag Explained: Running One-Liners

In the Lua programming language, the -e command-line flag allows users to directly execute small snippets of code without having to create or manage external script files. This article covers how the -e flag functions within the Lua standalone interpreter, how it can be combined for complex workflows, and common use cases including environment checks, debugging, and shell pipeline integration.

The -e option stands for "execute" or "evaluate." When passed to the lua executable followed by a string containing Lua code, the interpreter parses and runs that string immediately before terminating or proceeding with other arguments.

Basic Syntax and Usage

The standard syntax involves passing a quoted string containing valid Lua statements directly after the flag:

lua -e 'print("Hello, World!")'

Because shell environments typically interpret double and single quotes differently, wrapping the Lua statement in single quotes is standard practice to preserve string literals and special characters inside the Lua code.

Sequential Execution

Lua permits the use of multiple -e flags in a single command. The interpreter evaluates each statement sequentially from left to right in the same global environment:

lua -e 'x = 10' -e 'y = 20' -e 'print(x + y)'

In this example, variables defined in earlier -e blocks remain accessible in subsequent blocks during the same run.

Combining -e with Files and Interactive Mode

The -e flag can be combined with other interpreter flags and script files:

  • Interactive Mode (-i): You can run setup code via -e and enter interactive mode immediately afterward by adding the -i flag:

    lua -e 'data = {1, 2, 3}' -i

  • Pre-loading Modules: You can use -e to require modules or set global configurations before executing a script file:

    lua -e 'DEBUG = true' myscript.lua

Common Use Cases

  • Checking Interpreter Version: A fast way to confirm the active runtime version is running lua -e 'print(_VERSION)'.

  • Inline Arithmetic and Quick Testing: You can test standard library behavior or perform rapid calculations without opening an interactive session:

    lua -e 'print(math.sqrt(144) * 2)'

  • Shell Integration: The output of a Lua one-liner can be piped directly into standard Unix utilities like grep, awk, or redirected to files as part of shell automation.
