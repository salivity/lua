Build a Custom File Stream in Lua With Metatables

This article demonstrates how to create a custom stream abstraction in Lua that behaves identically to standard file objects created by io.open. By leveraging Lua's metatables and the __index metamethod, developers can implement in-memory buffers or network adapters that support familiar file operations like read, write, seek, and close, allowing them to interface seamlessly with functions that expect regular file handles.

Understanding the File Interface in Lua

Standard Lua file objects offer a consistent set of methods:

  • :read(...) to read bytes, lines, or entire contents.
  • :write(...) to write strings or numbers.
  • :seek(whence, offset) to reposition the cursor.
  • :close() to release the resource.
  • :lines(...) to iterate over lines.

To make a custom table mimic a file handle, assign it a metatable whose __index field maps to a table containing these methods.

Designing the Stream Class

Below is a complete implementation of a memory-backed stream (MemoryStream) that mimics a standard file object:

local MemoryStream = {}
MemoryStream.__index = MemoryStream

function MemoryStream.new(initial_data)
    local self = setmetatable({}, MemoryStream)
    self.buffer = initial_data or ""
    self.pos = 1 -- 1-based indexing for Lua strings
    self.closed = false
    return self
end

local function check_open(self)
    if self.closed then
        error("attempt to use a closed stream", 2)
    end
end

function MemoryStream:write(...)
    check_open(self)
    local args = {...}
    for _, val in ipairs(args) do
        local str = tostring(val)
        local before = self.buffer:sub(1, self.pos - 1)
        local after = self.buffer:sub(self.pos + #str)
        self.buffer = before .. str .. after
        self.pos = self.pos + #str
    end
    return self
end

function MemoryStream:read(...)
    check_open(self)
    local formats = {...}
    if #formats == 0 then
        formats = {"*l"}
    end

    local results = {}
    for _, fmt in ipairs(formats) do
        if self.pos > #self.buffer then
            table.insert(results, nil)
        elseif fmt == "*a" or fmt == "a" then
            local chunk = self.buffer:sub(self.pos)
            self.pos = #self.buffer + 1
            table.insert(results, chunk)
        elseif type(fmt) == "number" then
            local chunk = self.buffer:sub(self.pos, self.pos + fmt - 1)
            self.pos = self.pos + #chunk
            table.insert(results, #chunk > 0 and chunk or nil)
        elseif fmt == "*l" or fmt == "l" or fmt == "*L" or fmt == "L" then
            local newline_pos = self.buffer:find("\n", self.pos, true)
            local chunk
            if newline_pos then
                if fmt == "*l" or fmt == "l" then
                    chunk = self.buffer:sub(self.pos, newline_pos - 1)
                else
                    chunk = self.buffer:sub(self.pos, newline_pos)
                end
                self.pos = newline_pos + 1
            else
                chunk = self.buffer:sub(self.pos)
                self.pos = #self.buffer + 1
            end
            table.insert(results, chunk)
        else
            error("unsupported read format: " .. tostring(fmt), 2)
        end
    end

    return table.unpack(results)
end

function MemoryStream:seek(whence, offset)
    check_open(self)
    whence = whence or "cur"
    offset = offset or 0

    local base = self.pos - 1 -- convert to 0-based for arithmetic

    if whence == "set" then
        base = 0
    elseif whence == "cur" then
        -- base is already self.pos - 1
    elseif whence == "end" then
        base = #self.buffer
    else
        error("invalid option '" .. tostring(whence) .. "'", 2)
    end

    local new_pos = base + offset + 1
    if new_pos < 1 then
        return nil, "Invalid argument"
    end

    self.pos = new_pos
    return self.pos - 1
end

function MemoryStream:lines(...)
    check_open(self)
    local formats = {...}
    return function()
        if self.closed then return nil end
        return self:read(table.unpack(formats))
    end
end

function MemoryStream:close()
    check_open(self)
    self.closed = true
    self.buffer = nil
    return true
end

Implementing Key Components

  1. State Preservation: The instance stores internal state such as self.buffer and self.pos. When reading or writing, the cursor increments proportionally to the processed byte length.
  2. Method Resolution via __index: Assigning MemoryStream.__index = MemoryStream ensures any method call on a stream instance looks up functions defined on the MemoryStream table.
  3. Format Support: Standard file :read() handles numbers (byte count), *a (all remaining data), and *l (single line). Mirroring this signature ensures interoperability with functions written to accept normal file descriptors.
  4. Standard Seek Offsets: Lua files use 0-based indexing for seek results and offset values, while Lua strings use 1-based indexing. The arithmetic inside :seek normalizes these differences.

Usage Example

-- Create a new stream with initial data
local stream = MemoryStream.new("First line\nSecond line\n")

-- Read a single line
print(stream:read("*l")) -- Outputs: First line

-- Write data at current position
stream:write("Third line\n")

-- Rewind to start
stream:seek("set", 0)

-- Iterate through all lines
for line in stream:lines() do
    print(line)
end

stream:close()

This pattern provides a drop-in replacement for standard Lua I/O handles, making it ideal for mock testing, network response parsing, and compressed data streams without touching the local filesystem.
