How to Use LuaCov for Lua Code Coverage

This guide explains how to measure test suite effectiveness in the Lua programming language using LuaCov, a lightweight coverage analysis tool. You will learn how to install LuaCov via LuaRocks, instrument your test runs, generate detailed line-by-line coverage reports, and configure rules to exclude test files or external libraries from your metrics.

Installing LuaCov

The standard method to install LuaCov is through LuaRocks, the package manager for Lua modules. Open your terminal and run:

luarocks install luacov

This installs both the core coverage tracking module and the command-line utility used to generate human-readable reports.

Instrumenting Your Test Suite

LuaCov works by hooking into the Lua debug engine to count how many times each line of code is executed. To activate it, you load the luacov module before running your test suite.

If you run your tests with the standard Lua interpreter:

lua -lluacov test_runner.lua

If you use Busted, a popular Lua testing framework, you can enable coverage by passing the --coverage flag directly:

busted --coverage

Alternatively, you can manually require LuaCov at the very top of your main entry point or test runner script:

require("luacov")

When your test suite finishes running, LuaCov writes raw execution data into a file named luacov.stats.out in your project root.

Generating the Coverage Report

The raw stats file must be parsed into a readable format. Run the luacov command-line script in the directory where luacov.stats.out is located:

luacov

This creates a file named luacov.report.out. Inside, you will find:

  1. A summary table listing every executed file, total lines, code lines, non-code lines, and coverage percentages.
  2. A detailed source code view where each line is prefixed with the number of times it was hit during testing (or ***0*** if a line was never reached).

Configuring LuaCov

By default, LuaCov may track execution inside your test files, system libraries, and third-party dependencies. To filter your results, create a configuration file named .luacov in your project directory:

return {
    -- Include only files in your source directory
    include = {
        "^src/"
    },

    -- Exclude tests and external libraries
    exclude = {
        "^spec/",
        "^test/",
        "luarocks/"
    },

    -- Change output report filename if needed
    reportfile = "luacov.report.out",
    statsfile = "luacov.stats.out"
}

When you rerun the luacov command, it will apply these filters and produce an accurate representation of your actual application code coverage.
