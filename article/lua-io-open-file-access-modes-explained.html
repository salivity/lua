Lua io.open File Access Modes Explained

In Lua, the io.open function is the standard method for creating and interacting with file streams, relying on access mode strings to define how a file is handled. This guide provides a clear overview of every file access mode available in Lua, detailing the differences between read, write, append, update, and binary operations so you can choose the correct mode for your input/output tasks.

Basic Modes

  • "r" (Read Mode): This is the default mode if no mode parameter is provided. It opens an existing file strictly for reading. The file position is set to the beginning of the file. If the specified file does not exist, io.open returns nil along with an error message.
  • "w" (Write Mode): Opens a file strictly for writing. If the file already exists, its contents are completely erased (truncated to zero length). If the file does not exist, a new empty file is created.
  • "a" (Append Mode): Opens a file for writing, but unlike "w", existing content is preserved. All write operations automatically append data to the end of the file. If the file does not exist, a new one is created.

Update Modes

Adding a + symbol to a mode string enables both reading and writing capabilities:

  • "r+" (Read and Write / Update): Opens an existing file for both reading and writing. The initial file position is at the start, and existing content is preserved. The file must already exist, or the operation will fail.
  • "w+" (Write and Read / Truncate and Update): Opens a file for both reading and writing. If the file exists, all existing content is erased immediately upon opening. If the file does not exist, a new one is created.
  • "a+" (Append and Read / Update): Opens a file for both reading and writing. While reading can occur anywhere in the file (using file:seek), all write operations are automatically appended to the end of the file. If the file does not exist, it is created.

Binary Mode

  • "b" (Binary Modifier): On systems that distinguish between text and binary files (such as Windows), appending a b to any mode string prevents automatic newline translation (e.g., converting \r\n to \n). You can combine it with any of the standard modes, such as "rb", "wb", "ab", "r+b", "w+b", or "a+b". On POSIX-compliant systems like Linux and macOS, the b flag is ignored because text and binary files are handled identically.
