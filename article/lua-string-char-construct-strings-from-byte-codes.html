Lua string.char: Construct Strings from Byte Codes

The string.char function in Lua is a standard library function used to generate strings directly from integer byte values. This article covers the syntax of string.char, how it translates individual and multiple numerical codes into characters, how to convert dynamic tables of bytes into strings, and key behavior regarding binary data and input limits.

What is string.char?

In Lua, string.char is part of the standard string library. It takes zero or more integers representing numerical byte values—typically corresponding to ASCII or raw binary values—and converts them into their character equivalents, concatenating them into a single string.

Because Lua strings are 8-bit clean, a character in Lua is defined as an 8-bit byte. This means string.char can handle any byte value from 0 up to 255, including the null character (\0).

Syntax and Parameters

string.char(...)
  • Parameters: Zero or more integers representing byte codes.
  • Return Value: A string whose length matches the number of integer arguments provided, with each character matching the byte value at that position.

If called with no arguments (string.char()), it returns an empty string ("").

Basic Examples

Generating a Single Character

Passing a single ASCII code returns a string containing that single character:

local letterA = string.char(65)
print(letterA) -- Output: A

Passing Multiple Byte Codes

You can pass multiple comma-separated integers to build words, phrases, or binary sequences in a single call:

local greeting = string.char(72, 101, 108, 108, 111)
print(greeting) -- Output: Hello

Constructing Strings from Arrays of Bytes

When working with network protocols, file parsers, or cryptographic routines, byte values are often stored in an array-like table. You can use Lua's unpack mechanism to pass an array directly into string.char:

local byte_list = {87, 111, 114, 108, 100}

-- In Lua 5.2+:
local text = string.char(table.unpack(byte_list))
print(text) -- Output: World

-- In Lua 5.1:
-- local text = string.char(unpack(byte_list))

Note: For extremely large tables (typically tens of thousands of elements), unpacking the entire table at once may exceed the Lua call stack limit. In such cases, process the table in smaller chunks.

Handling Binary Data and Null Bytes

Because Lua strings are not null-terminated, string.char can safely create strings that include null bytes or arbitrary binary values:

local binary = string.char(0, 1, 2, 255)
print(#binary) -- Output: 4

The length operator (#) correctly counts all bytes, regardless of whether a null byte (0) is present.

Value Range and Error Handling

Each argument passed to string.char must be an integer within the range [0, 255]. Passing numbers outside this range or passing non-numeric types will result in a runtime error:

  • Values greater than 255 or less than 0 will throw a bad argument or value out of range error.
  • Non-integer floating-point numbers will throw an error in modern Lua versions (Lua 5.3 and newer).

The Reciprocal: string.byte

The inverse of string.char is string.byte, which extracts the numerical byte codes from an existing string. Together, string.char and string.byte form the primary interface for low-level byte and binary string manipulation in Lua.
