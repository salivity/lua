Wireshark Lua Dissector Using the Proto Class

Creating a custom protocol dissector in Wireshark via Lua's Proto class allows developers to parse proprietary or unsupported network protocols without recompiling Wireshark from source. This guide demonstrates how to declare a new Proto object, define protocol fields using ProtoField, construct a detailed protocol decoding tree, write the main dissector callback function, and register the script with Wireshark's packet-handling tables.

1. Initialize the Protocol

Every custom dissector begins by instantiating the Proto class. This defines the protocol's internal identifier and user-facing description.

local my_proto = Proto("myproto", "My Custom Protocol")

2. Define Protocol Fields

Protocol fields determine how individual bytes in the payload are displayed and filtered within Wireshark. Fields are defined using the ProtoField class and registered directly into the protocol's .fields table.

local f_version = ProtoField.uint8("myproto.version", "Version", base.DEC)
local f_msg_type = ProtoField.uint8("myproto.type", "Message Type", base.HEX)
local f_length   = ProtoField.uint16("myproto.length", "Payload Length", base.DEC)
local f_payload  = ProtoField.string("myproto.payload", "Payload Data")

my_proto.fields = { f_version, f_msg_type, f_length, f_payload }

3. Implement the Dissector Function

The core logic resides in the dissector method of the Proto object. This function accepts three arguments:

  • buffer: The Tvb (Testy Virtual Buffer) containing the raw packet data.
  • pinfo: The packet information structure holding metadata (e.g., source, destination, columns).
  • tree: The root TreeItem used to build the Wireshark protocol details pane.
function my_proto.dissector(buffer, pinfo, tree)
    -- Guard against incomplete packets
    local length = buffer:len()
    if length < 4 then return end

    -- Update the Wireshark GUI columns
    pinfo.cols.protocol = my_proto.name
    pinfo.cols.info = "Custom Protocol Packet"

    -- Add the top-level protocol subtree
    local subtree = tree:add(my_proto, buffer(), "My Custom Protocol Data")

    -- Parse and add individual fields from buffer offsets: (offset, length)
    subtree:add(f_version, buffer(0, 1))
    subtree:add(f_msg_type, buffer(1, 1))
    subtree:add(f_length, buffer(2, 2))

    local payload_len = buffer(2, 2):uint()
    if length >= 4 + payload_len then
        subtree:add(f_payload, buffer(4, payload_len))
    end
end

4. Register the Dissector

To make Wireshark trigger the dissector on relevant traffic, bind the Proto instance to a transport-layer table, such as UDP or TCP ports:

local udp_port = DissectorTable.get("udp.port")
udp_port:add(9999, my_proto)

For TCP-based protocols requiring stream reassembly, bind the protocol to "tcp.port" instead.

5. Load and Test the Script

  1. Save the code into a .lua file (for example, my_proto.lua).
  2. Place the file in Wireshark’s personal plugins directory, which can be found under Help > About Wireshark > Folders > Personal Lua Plugins.
  3. Reload active Lua plugins inside Wireshark by pressing Ctrl + Shift + L (or Cmd + Shift + L on macOS).
  4. Inspect or capture packets on the configured port to verify that the protocol hierarchy and custom fields appear in the packet details pane.
