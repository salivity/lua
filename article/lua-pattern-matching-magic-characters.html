Lua Pattern Matching Magic Characters

Lua does not use traditional regular expressions for text processing; instead, it provides a lightweight pattern-matching engine built directly into its standard string library. This article provides a comprehensive reference of all twelve default "magic characters" used in Lua patterns—^, $, (, ), %, ., [, ], *, +, -, and ?—and explains how each character functions when searching, capturing, and replacing text in functions such as string.find, string.match, string.gmatch, and string.gsub.

Anchors

  • ^ (Caret): Anchors the match to the beginning of the subject string. When placed at the start of a pattern, the match succeeds only if the target string begins with the specified pattern.
  • $ (Dollar sign): Anchors the match to the end of the subject string. When placed at the end of a pattern, the match succeeds only if the target string concludes with the specified pattern.

The Wildcard and the Escape Character

  • . (Period): Matches any single character, including newline characters.
  • % (Percent sign): Acts as the universal escape character in Lua patterns.
    • Prefixing any magic character with % (e.g., %%, %., %?) treats it as a literal character rather than an operator.
    • Prefixing alphanumeric characters defines built-in character classes (such as %a for letters, %d for digits, and %s for whitespace). Uppercase variants represent the complement of the class (such as %D for non-digits).
    • Prefixing a digit 1 through 9 creates a backreference to a previous capture.
    • %bxy matches a balanced string starting with character x and ending with character y (e.g., %b()).

Repetition Modifiers (Quantifiers)

Pattern repetition characters in Lua are always applied to the preceding character, character class, or set:

  • * (Asterisk): Matches zero or more repetitions of the preceding item. It is greedy and matches the longest possible sequence.
  • + (Plus): Matches one or more repetitions of the preceding item. It is greedy and matches the longest possible sequence.
  • - (Hyphen/Minus): Matches zero or more repetitions of the preceding item. Unlike *, it is non-greedy (lazy) and matches the shortest possible sequence.
  • ? (Question mark): Matches zero or one repetition of the preceding item, effectively making it optional.

Sets and Captures

  • [ and ] (Square brackets): Define a custom character class (set). For example, [aeiou] matches any vowel.
    • A range of characters can be defined using a hyphen, such as [0-9] or [a-z].
    • Placing a ^ as the very first character inside the brackets negates the set, matching any character not enclosed (e.g., [^0-9] matches any non-digit).
  • ( and ) (Parentheses): Define sub-pattern captures. When a match is found, the substrings matching the enclosed patterns are stored and can be retrieved as multiple return values or referenced in substitutions. If parentheses are empty (()), Lua captures the current string position as a number.
