Inverting Character Classes in Lua Pattern Matching

In Lua pattern matching, built-in character classes can be inverted to match their exact opposite by converting the class identifier to uppercase. This article explains how lowercase classes such as %a, %d, and %s correspond to specific sets of characters, how their uppercase counterparts (%A, %D, and %S) match the complement of those sets, and how to apply this notation in practical string-manipulation tasks.

The Uppercase Inversion Rule

Lua uses a lightweight pattern-matching engine rather than standard regular expressions. In this system, predefined character classes are represented by a percent sign (%) followed by a single character.

The rule for inverting these classes is straightforward: any lowercase character class represents a specific category, while its uppercase counterpart represents all characters not in that category (the complement of the class).

Common Inverted Classes

  • %a vs. %A: %a matches all letters (uppercase and lowercase). %A matches any character that is not a letter.
  • %d vs. %D: %d matches any decimal digit (0 through 9). %D matches any character that is not a digit.
  • %s vs. %S: %s matches any whitespace character (space, tab, newline, carriage return). %S matches any non-whitespace character.
  • %w vs. %W: %w matches any alphanumeric character. %W matches any non-alphanumeric character.
  • %p vs. %P: %p matches any punctuation character. %P matches any non-punctuation character.

Practical Examples in Lua

The uppercase inverted classes are commonly used with standard string library functions such as string.gsub, string.match, and string.gmatch.

Sanitizing Non-Digit Input

To remove all non-numeric characters from a string (such as formatting from a phone number), use %D with string.gsub:

local raw_phone = "(555) 123-4567"
local cleaned_phone = string.gsub(raw_phone, "%D", "")

print(cleaned_phone) -- Output: 5551234567

In this example, every character that is not a digit is matched by %D and replaced with an empty string.

Splitting Words by Non-Whitespace

To iterate over sequences of non-whitespace characters, use %S+ with string.gmatch:

local sentence = "Lua pattern matching is fast."

for word in string.gmatch(sentence, "%S+") do
    print(word)
end

%S+ matches one or more consecutive characters that are not spaces, tabs, or line breaks, effectively isolating individual words.

Removing Non-Alphabetic Characters

To strip punctuation, symbols, and numbers from a text string, use %A:

local mixed_text = "User_123: Hello, World!"
local letters_only = string.gsub(mixed_text, "%A", "")

print(letters_only) -- Output: UserHelloWorld

Inversion Inside Custom Character Sets

When creating custom character sets using brackets ([]), the uppercase classes retain their inverted meaning. For example, [%D%S] matches any character that is either not a digit or not whitespace.

However, if you want to invert an entire custom set, Lua provides the ^ anchor at the start of the bracketed set (such as [^0-9]), which functions similarly to the uppercase notation for built-in classes.
