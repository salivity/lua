Floating-Point Division by Zero in Lua

In the Lua programming language, division by zero involving floating-point numbers does not raise a runtime error; instead, it strictly adheres to the IEEE 754 standard for floating-point arithmetic. Depending on whether the numerator is positive, negative, or zero, the operation evaluates to positive infinity (inf), negative infinity (-inf), or Not a Number (nan).

IEEE 754 Compliance

Lua represents floating-point values internally using the host platform's C double type, which typically implements IEEE 754 double-precision arithmetic. Because the IEEE 754 standard defines mathematical representations for overflow and undefined operations, floating-point operations do not interrupt execution when dividing by zero.

Evaluation Scenarios

When performing floating-point division by zero (x / 0.0 or x / 0), Lua produces three distinct outcomes based on the numerator:

  • Positive Numerator: Dividing any positive non-zero floating-point number by zero returns positive infinity.

    print(1.0 / 0.0) -- Output: inf

  • Negative Numerator: Dividing any negative non-zero floating-point number by zero returns negative infinity.

    print(-1.0 / 0.0) -- Output: -inf

  • Zero Numerator: Dividing zero by zero is mathematically indeterminate and returns nan.

    print(0.0 / 0.0) -- Output: nan (or -nan depending on platform)

Floats vs. Integers in Modern Lua

Since Lua 5.3 introduced distinct integer and float subtypes under the number type, behavior depends on the operand types and operators:

  • Standard division using the / operator always promotes operands to floating-point numbers. Consequently, 5 / 0 evaluates to inf rather than throwing an error, even if the inputs appear as integer literals.
  • Floor division using the // operator between two integers (e.g., 5 // 0) attempts integer division and raises a runtime error: attempt to divide by zero.
  • Floor division where at least one operand is a float (e.g., 5.0 // 0) follows floating-point rules and evaluates to inf or -inf.

Checking for Infinity and NaN

Lua provides standard ways to check for the results of division by zero:

  • Infinity: Positive infinity is represented in Lua by the constant math.huge. You can verify an infinity result by checking if value == math.huge or value == -math.huge.
  • NaN: By IEEE 754 definition, nan does not equal any value, including itself. You can test if a result is nan using the condition value ~= value, which only evaluates to true when value is nan.
