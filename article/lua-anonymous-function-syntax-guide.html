Lua Anonymous Function Syntax Guide

This article provides a concise overview of how to declare and use anonymous functions in the Lua programming language. In Lua, functions are first-class values, meaning they can be created without names, stored in variables, passed as arguments, and returned from other functions. Below, you will find the exact syntax used for anonymous functions, how they compare to standard function declarations, and common use cases such as callbacks and closures.

Basic Syntax

In Lua, an anonymous function is declared using the function keyword, followed by an optional parameter list enclosed in parentheses, the function body, and the end keyword to terminate the block:

function(parameter1, parameter2, ...)
    -- function body
    return result
end

Unlike some modern languages, Lua does not have a shortened "arrow" or "lambda" syntax (such as =>). All anonymous functions must use the full function(...) ... end structure.

Assigning to Variables

Because functions are first-class values, standard named function declarations in Lua are merely syntactic sugar for assigning an anonymous function to a variable.

The standard declaration:

local function add(a, b)
    return a + b
end

Is functionally identical to the anonymous assignment:

local add = function(a, b)
    return a + b
end

Passing as Inline Callbacks

A primary use case for anonymous functions is providing inline logic directly to higher-order functions, such as sorting functions or event listeners, without polluting the local or global namespace with single-use function names.

For example, using an anonymous function with table.sort to sort a list in descending order:

local numbers = {5, 2, 8, 1, 9}

table.sort(numbers, function(a, b)
    return a > b
end)

Creating Closures and Factory Functions

Anonymous functions can be defined inside other functions and returned. These functions capture the lexical scope of the enclosing function, creating a closure:

local function createMultiplier(factor)
    return function(x)
        return x * factor
    end
end

local double = createMultiplier(2)
print(double(5)) -- Outputs: 10

Immediate Execution

You can immediately invoke an anonymous function by wrapping the definition in parentheses (or directly applying parentheses) followed by the invocation arguments:

local result = (function(x, y)
    return x * y
end)(4, 5)

print(result) -- Outputs: 20
