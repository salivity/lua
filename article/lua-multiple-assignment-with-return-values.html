Lua Multiple Assignment with Return Values

In Lua, multiple assignment allows you to bind several variables to multiple values in a single statement. When combined with functions that return multiple results, Lua dynamically aligns the list of variables on the left with the values returned on the right. This article explains how Lua maps return values to variables, how it handles mismatches in count, and how expression positioning alters the number of values retained.

Basic Syntax and Value Mapping

Lua functions can natively return multiple values separated by commas. In a multiple assignment statement, Lua evaluates the function on the right-hand side and assigns each returned value sequentially to the corresponding variable on the left-hand side.

local function getCoordinates()
    return 10, 20, 30
end

local x, y, z = getCoordinates()
-- x = 10, y = 20, z = 30

Handling Mismatched Counts

When the number of variables does not match the number of return values, Lua adjusts the list using straightforward truncation and padding rules:

  • More variables than return values: Any variable that does not receive a corresponding return value is assigned nil.
  • More return values than variables: Any extra values returned by the function are discarded.
-- Discarding extra values
local a, b = getCoordinates()
-- a = 10, b = 20 (30 is discarded)

-- Padding with nil
local p, q, r, s = getCoordinates()
-- p = 10, q = 20, r = 30, s = nil

The Position Rule for Multi-Return Expressions

How many values a function provides depends strictly on where the function call appears in the assignment list:

  1. At the end of the list: If a function call is the last (or only) expression in the assignment list, it produces as many return values as needed to fulfill the remaining variables.
  2. Not at the end of the list: If a function call is followed by another expression, Lua adjusts its return values to exactly one, discarding the rest.
local function pair()
    return "first", "second"
end

-- 'pair()' is not last: its returns are truncated to 1
local a, b, c = pair(), "extra"
-- a = "first", b = "extra", c = nil

-- 'pair()' is last: it provides all its return values
local x, y, z = "extra", pair()
-- x = "extra", y = "first", z = "second"

Forcing a Single Return Value

You can explicitly limit a function call to return only its first result by wrapping the call in parentheses. The enclosing parentheses turn the multi-value return into a single-value expression.

local x, y = (getCoordinates())
-- x = 10, y = nil (parentheses force only the first value to be used)

Common Applications

Multiple assignment with return values is heavily leveraged across standard Lua idioms:

  • Error handling: Many functions return the result on success, or nil followed by an error message on failure (e.g., local file, err = io.open("missing.txt", "r")).
  • Protected calls: pcall returns a boolean status flag as the first value, followed by either the returned results or an error object (e.g., local success, result = pcall(riskyFunction)).
  • Pattern matching: Functions such as string.find return starting and ending indices simultaneously (e.g., local startIdx, endIdx = string.find("hello", "ll")).
