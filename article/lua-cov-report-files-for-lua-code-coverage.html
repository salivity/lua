LuaCov Report Files for Lua Code Coverage

LuaCov is the standard code coverage analysis tool for the Lua programming language, used to monitor test execution and track uncalled code paths. This article outlines the specific output files generated by LuaCov to display line-by-line execution counts, explains their structure, and covers how these files are generated and configured.

The Intermediate Statistics File: luacov.stats.out

When a Lua script executes with the LuaCov runner active (typically via lua -lluacov test.lua), LuaCov does not immediately produce a human-readable text document. Instead, it hooks into the Lua debug library and records execution data in an intermediate file:

  • Default Filename: luacov.stats.out

This file is a raw, non-human-readable tally of the line hits across all files loaded by the Lua state. Because tests or test suites may run in multiple processes or separate invocations, LuaCov appends to or updates luacov.stats.out across runs until explicitly cleared.

The Human-Readable Report: luacov.report.out

To convert the raw execution metrics into a line-by-line hit report, developers run the standalone luacov command from the terminal. This parses the stats file and maps the numbers directly against the source code files.

  • Default Filename: luacov.report.out

luacov.report.out is the primary file that displays line-by-line execution hits. It is a plain text file structured into sections for each analyzed Lua source file.

Structure of the Line-by-Line Output

Inside luacov.report.out, each source file is displayed line-by-line alongside its execution count on the left-hand side. The output adheres to standard markers:

  • Execution Hits (Numeric Count): If a line was executed, the exact number of executions (hits) is shown (e.g., 1, 5, 42).
  • Unexecuted Lines (***0): Lines of executable code that were never evaluated during the run are flagged with ***0, making dead or uncovered code easy to locate using search tools.
  • Non-Executable Lines (Empty): Comments, empty lines, and syntax markers (such as end or else in certain positions) show no count, signifying that Lua did not compile them as executable bytecode instructions.

At the bottom of each file's section, and at the end of the entire report, LuaCov includes summary statistics detailing:

  • Total executable lines
  • Covered lines
  • Total execution percentage

Customizing Report Output Files

The default filenames can be altered by creating a configuration file named .luacov in the project root directory. Inside this configuration script, the paths for both files can be overridden:

return {
    statsfile = "custom_coverage.stats.out",
    reportfile = "coverage_report.txt"
}

HTML Report Formats

By default, core LuaCov only outputs the plain text luacov.report.out. However, when using extended reporters such as luacov-reporter-html, LuaCov can produce rich HTML files:

  • Common Output: An index.html file along with individual .html files for each covered module, displaying identical line-by-line hit data with visual color highlighting (green for covered lines, red for uncovered lines).
