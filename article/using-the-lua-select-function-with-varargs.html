Using the Lua select Function with Varargs

In the Lua programming language, functions can accept an arbitrary number of parameters using the variable argument (vararg) expression, denoted by three dots (...). This article explains how Lua's built-in select function works to inspect the total count of these arguments and retrieve specific values from them efficiently without packing them into a table.

The Role of the select Function

The standard signature of the function is select(index, ...). It takes an index or selector as its first argument, followed by the variable arguments to be evaluated. Depending on the value passed as the first parameter, select performs one of two operations: counting the arguments or slicing and returning them starting from a specific position.

Counting Arguments with select('#', ...)

When the string '#' is provided as the first argument, select returns the total number of arguments passed in the vararg expression.

local function countArgs(...)
    local count = select('#', ...)
    print("Total arguments:", count)
end

countArgs(10, "hello", nil, true) -- Total arguments: 4

Using select('#', ...) is the standard, idiomatic way to count arguments in Lua because it correctly counts nil values. Packing arguments into a table via {...} and using the length operator # can produce unreliable results if trailing or intermediate nil values exist, as nil creates "holes" in Lua sequences.

Retrieving Arguments by Numeric Index

When a positive integer n is supplied as the first argument, select drops the first n - 1 elements and returns all remaining arguments from position n onward.

local function getFromIndex(...)
    -- Returns the 2nd argument and everything after it
    return select(2, ...)
end

local a, b, c = getFromIndex("first", "second", "third", "fourth")
print(a, b, c) -- Output: second    third    fourth

If you only need a single specific argument, you can isolate it by wrapping the call in parentheses to adjust the return values to a single item:

local function getSingleArg(n, ...)
    -- Parentheses force Lua to evaluate only the first returned value
    return (select(n, ...))
end

print(getSingleArg(3, "A", "B", "C", "D")) -- Output: C

Using Negative Indices

Modern versions of Lua (Lua 5.3 and newer) support negative numbers for the index. A negative index counts backward from the end of the argument list, where -1 represents the last argument, -2 represents the second-to-last, and so on.

local function getLastArg(...)
    return select(-1, ...)
end

print(getLastArg("apple", "banana", "cherry")) -- Output: cherry

Performance Benefits

The primary advantage of select over packing arguments into an array with {...} is efficiency. Creating a table requires memory allocation and invokes the garbage collector, which adds overhead in performance-critical code or tight loops. The select function operates directly on Lua's internal virtual machine stack, inspecting and retrieving parameters with zero table allocations.
